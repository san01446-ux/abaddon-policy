ABADDON v6.4.1 — 안정화 · 텍스트 퍼스트 · 서버 테마

[핵심 안정화]
- 저장 파일을 임시 파일에 완전히 기록하고 JSON을 다시 읽어 검증한 뒤 원자적으로 교체합니다.
- 기존 정상 저장본은 survival_data.json.bak 형태로 한 단계 보존합니다.
- 주 저장 파일이 손상되면 시작 시 .bak 정상본을 자동으로 읽어 복구합니다.
- 관리자용 !데이터백업 명령을 추가했으며 최근 수동 백업 5개를 유지합니다.
- 알 수 없는 명령은 비슷한 명령 후보 또는 !명령어 검색 방법을 안내합니다.
- 누락 인자·잘못된 형식은 해당 명령의 실제 사용법을 표시합니다.
- 예상하지 못한 오류에는 8자리 사건 번호를 부여해 Render 로그와 사용자 제보를 대조할 수 있습니다.

[새 접근성 기능]
- !안정화상태: 버전·가이드·데이터·이미지 정책 확인
- !오늘할일: 출석·운세·오늘의 퀴즈·일일 퀘스트와 추천 루틴 확인
- !서버브리핑: 현재 날씨·돌연변이 위험구역·보급선·주간 기지 방어 요약
- !서버테마 / !서버테마미리보기 / !서버테마설정
- 텍스트형 테마 5종: 검은 성당, 폐허 도시, 격리 연구소, 황혼 전초기지, 종말 방송국
- !안정화도움말

[명령어 드롭다운]
- !명령어에 '안정화 / 서버 테마' 최상위 카테고리를 추가했습니다.
- v6.3.7~v6.4.1 최근 기능 52개 토큰이 가이드에 노출되는지 !테스트 상세에서 검사합니다.
- 최상위 카테고리는 17개로 Discord 선택 메뉴 제한 25개 이내입니다.

[이미지 정책]
- 생활·장비·제작·보물·펫·기지·카지노·갈갈이 게임 이미지를 첨부하지 않습니다.
- 결과는 텍스트·이모지·버튼·진행률 중심으로 표시합니다.
- 월드보스 전용 이미지는 예외로 유지합니다.
- 전체 봇 패키지에서는 월드보스 외 기존 게임 이미지 에셋을 제거해 용량과 배포 복잡도를 줄였습니다.
- 사용자 아바타, 서버 아이콘, 진단/내보내기 파일은 게임 이미지 정책 대상이 아닙니다.

[유지 사항]
- 월드보스 기능·연출·보상 규칙은 변경하지 않았습니다.
- 기존 경제 수치, 확률, 기지 난이도, 장비·펫 데이터, 사용자 저장 데이터 형식은 유지합니다.
- 기존 서버 리뉴얼 기능은 유지하며, 신규 5종 테마는 브리핑 색상·이모지·문구만 바꿉니다.

[홈페이지]
- v6.4.1 버전, 안정화 기능, 서버 테마, 텍스트 우선 정책을 반영했습니다.
- 메인 페이지의 게임 이미지 태그와 사용하지 않는 사이트 이미지 에셋을 제거하고 텍스트 카드 중심으로 정리했습니다.
- 명령어 검색과 업데이트 기록을 v6.4.1로 동기화했습니다.
