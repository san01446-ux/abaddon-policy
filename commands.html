🎵 아바돈 뮤직봇 · 노래 명령어

노래는 전용 봇 아바돈 뮤직봇이 담당합니다. 음성 채널에 들어간 뒤 !뮤직 재생 곡명을 입력하세요. 반복은 off/one/all, 자동재생을 켜면 대기열이 끝난 뒤 비슷한 곡을 이어서 틀고, 대기시간(1~60분)으로 노래가 끝난 뒤 나가기까지의 시간을 정합니다. 자동재생·대기시간·볼륨 변경은 서버 관리자 또는 DJ 역할이 필요합니다. 뮤직봇 초대하기 →

🆕 처음 시작 · v20.5

처음 왔다면 !시작 하나면 됩니다. 가입부터 튜토리얼 보상까지 버튼으로 안내하며, 예전 !처음 · !첫10분도 같은 화면을 엽니다. !서버순위는 이번 주 활동 생존자 수로 매긴 서버 대항 순위이고, 관리자는 !서버순위공개 끄기로 서버 이름을 숨길 수 있습니다.

☣️ 최신 핵심 기능 · v20.5.7

100층 도트 로그라이크, 선택형 AI 대화·개인 DM 알림, 게임별 다중 임시 음성 로비와 수면방을 반영했습니다. 음성 로비·수면방 설치는 ABADDON 운영진 전용이며, 설치된 로비는 누구나 사용할 수 있습니다.

🌐 웹 대시보드 · v20.5.7

외부 알림 등록·삭제, 보안·로그·환영 설정, GIF 반응, 버튼 역할은 인증 웹 대시보드에서 관리하고, LIVE 명령어센터는 공개 명령 전체를 검색합니다. 게임 실행형 기능은 Discord에서 그대로 사용합니다.

📡 외부 방송 알림 · 4 플랫폼

YouTube·Twitch·치지직(CHZZK)·SOOP 알림 등록·삭제는 서버 관리자가 웹 대시보드 [외부 알림] 탭에서 합니다. 일반 멤버는 !알림신청으로 요청하고 운영진이 !알림승인으로 승인합니다. SOOP은 API 승인 후 SOOP_CLIENT_ID를 Bot Worker에 추가하면 활성화됩니다.
