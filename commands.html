🌐 웹 대시보드 · v19.3

설정형 기능은 인증 웹 대시보드에서 관리하고, LIVE 명령어센터는 공개 명령 전체를 검색합니다. 게임 실행형 기능은 Discord에서 그대로 사용합니다.

🚘 FiveM · 인생서버 양방향 연동 v19.6.3

FiveM이 ABADDON Live Feed 릴레이에 아웃바운드 방식으로 연결되는 관리자용 양방향 브리지입니다. v19.6.3에서는 기존 Discord 구조를 유지한 채 인생서버 카테고리/누락 채널을 추가하고, 공지·일반·신고·운영로그·테스트·음성/직업무전에 맞는 권한을 미리보기 후 적용·복구할 수 있습니다. MariaDB 비밀번호나 Cfx Registration Key를 Discord에 저장하지 않습니다. 접속·퇴장·근무·경찰/EMS 긴급신고·관리자 조치는 지정 채널에 자동 기록할 수 있으며, FiveM의 Discord 식별자가 제공되면 직업 근무 상태와 Discord 역할도 동기화합니다.

📡 외부 방송 알림 · 4 플랫폼

YouTube·Twitch·치지직(CHZZK)·SOOP 알림을 통합 관리합니다. SOOP은 API 승인 후 SOOP_CLIENT_ID를 Bot Worker에 추가하면 활성화됩니다.
