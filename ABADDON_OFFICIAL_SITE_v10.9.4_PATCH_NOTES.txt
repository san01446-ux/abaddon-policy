ABADDON v10.9.4 카드 테이블 이미지·한글 출력 패치
배포일: 2026-08-04

[핵심 변경]
1. 카드게임 25종의 진행 메시지에 상태별 PNG 테이블을 연결했습니다.
   - 패를 내거나 뽑을 때, 베팅할 때, 차례가 바뀔 때 같은 메시지의 이미지를 새로 생성합니다.
   - 포커·화투·블랙잭·바카라·섯다·원카드·조커잡기는 전용 테이블을 사용합니다.
   - 나머지 종목은 현재 행동·차례·손패 수·베팅을 정리한 공용 이미지 테이블을 사용합니다.

2. 핵심 6개 게임 계열의 비공개 손패를 PNG로 표시합니다.
   - 포커, 맞고·고스톱, 블랙잭, 섯다, 원카드, 조커잡기
   - 내 패 이미지는 본인에게만 보이는 임시 응답으로 전송합니다.
   - 공개 테이블과 관전자 화면에는 비공개 패를 노출하지 않습니다.

3. 이미지 안의 한글 깨짐과 잘림을 보강했습니다.
   - 서버에 설치된 한글 글꼴을 우선 사용합니다.
   - 글꼴이 없으면 Noto Sans CJK KR을 /tmp에 런타임 캐시합니다.
   - 자동 줄바꿈, 글꼴 축소, 말줄임표, 박스 내부 폭 제한을 공용 처리합니다.
   - 긴 닉네임·긴 설명·큰 숫자·많은 손패를 안전하게 배치합니다.

4. 기존 PNG 정보 화면도 같은 글꼴·레이아웃 엔진을 사용합니다.
   - !정보 / !생존대시보드
   - !세계지도 / !지도대시보드
   - !카드대시보드 / !카드도감

5. 홈페이지 문장을 더 짧고 쉽게 다듬었습니다.
   - 한국어 메인과 English 페이지는 계속 분리됩니다.
   - 첫 화면, 최신 패치 안내, 최신 명령 설명을 간결하게 수정했습니다.
   - 카드 테이블·화투·비공개 손패 미리보기를 추가했습니다.

[새 명령]
한국어: !이미지검수, !이미지검수 상세
English: !imageaudit, !imageaudit detail
별칭: !renderaudit, !cardimageaudit

[함께 최신화]
!테스트 상세: v10.9.4에서 수정한 이미지·글꼴·테이블 경로만 검사
!패치노트: v10.9.4 실제 적용 내용만 표시
홈페이지 명령어·업데이트 페이지·명령어 매니페스트: v10.9.4 동기화

[중요]
실제 Discord Gateway와 여러 사용자의 동시 버튼 클릭은 제작 환경에서 실행하지 못했습니다.
운영 적용 전 테스트 서버에서 게임 계열별로 1판씩 진행해 메시지 이미지 교체와 비공개 손패를 확인하세요.
