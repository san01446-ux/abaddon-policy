ABADDON v7.7.0 — 폐허 파밍·생활 기술 확장 패치
패치 날짜: 2026-08-03

[신규: 지역 선택형 폐허 파밍]
단순 채집 명령을 복제하지 않고, 지역 선택·스태미나·위험도·현장 판단·후속 처리로 이어지는 생활 루프를 추가했습니다.

파밍 지역 4종
1. 버려진 대형마트 — 식량과 생활 물자 중심
2. 붕괴 주거구역 — 고철·나무·약초와 폐품 중심
3. 지하 화물역 — 광석·보물 파편과 봉인 물자 중심
4. 흑색 격리구역 — 오염 표본·설계도 조각과 미감정 보물 중심

주요 명령어
- !파밍 / !파밍지역
- !파밍출발 지역
- !파밍선택 전투/회피/구조/추가탐색
- !파밍기록

[랜덤 인카운트]
파밍 도중 현장 사건이 발생할 수 있습니다.
- 전투: 전투력으로 위협을 돌파하고 봉쇄 구역을 노립니다.
- 회피: 특수 회수품을 포기하고 안전 물자를 확보합니다.
- 구조: 생존 신호를 우선해 연구 자료와 위치 정보를 얻습니다.
- 추가 탐색: 더 깊은 구역을 조사하지만 부상 위험이 있습니다.

선택 대기 상태는 저장됩니다. 버튼이 사라지거나 봇이 재접속해도 !파밍선택으로 이어갈 수 있습니다. 현장 신호가 끝난 경우 다음 명령 실행 시 안전 회피로 한 번만 자동 정산됩니다.

[회수 물자]
- 식량
- 나무·고철·광석·약초
- 보물 파편
- 폐허 회로
- 오염 표본
- 설계도 조각
- 미감정 보물
- 미감정 폐품

상위 회수품 배정값은 서버 내부 테이블에서만 관리하며 명령 응답과 공식 홈페이지에는 수치를 표시하지 않습니다.

[신규: 폐허 복구 공방]
미감정 폐품은 공방에서 감정한 뒤 분해하거나 수리할 수 있습니다.
- !공방
- !폐품감정 [ID]
- !폐품분해 [ID]
- !폐품수리 [ID]

분해는 재료 회수, 수리는 식량과 고철을 사용한 완제품 복구입니다. 기존 장비 수리·장착 장비와는 별개이며 플레이어 장비를 변경하지 않습니다.

[신규: 전파 해독 미니게임]
- !전파탐색
- !신호해독 번호
- !주파수기록

수신된 패턴을 버튼 또는 번호로 해독합니다. 성공 기록은 생활 연구 자료와 연결됩니다.

[신규: 일일 납품 계약]
- !의뢰게시판
- !계약수락 번호
- !납품
- !계약현황

매일 사용자별 계약 3개가 구성됩니다. 자원을 즉시 판매하는 시장과 달리 요구 수량을 준비해 한 번만 제출하는 주문형 콘텐츠입니다.

[신규: 생활 연구·설계도]
- !연구소
- !연구시작 기술
- !연구진행
- !설계도

연구 기술
- 현장 배급 최적화
- 폐품 회수 공정
- 주파수 잡음 필터
- 생존 계약망

[드롭다운 최신화]
게임센터의 생활 카테고리에 ‘폐허 파밍·생활 기술’ 기능군을 추가했습니다.
신규 기능 21개가 드롭다운에서 실행되며 각 기능은 정확히 한 기능군에만 연결됩니다.

[중복 기능 분리]
- 채집·광산·벌목: 기존 즉시 기본 자원 활동 유지
- 땅파기: 기존 굴착·미감정 보물 중심 활동 유지
- 개인 원정: 기존 개인 탐험 콘텐츠 유지
- 길드 파견: 길드 금고·역할 편성·비동기 공동 보상 유지
- 폐허 파밍: 지역·스태미나·인카운트·폐품·계약·연구 전용 데이터 사용

기존 기능을 대체하거나 폐기하지 않습니다.

[안정화]
- 사용자별 비동기 잠금
- 파밍·인카운트·폐품에 고유 ID 사용
- 인카운트 결과 한 번만 정산
- 재접속 후 선택 명령 복구
- 일일 계약 완료 기록으로 중복 납품 방지
- 미감정 보물함이 가득 차면 보물 파편으로 안전 대체
- 읽기 전용 !770안정화검수 추가
- 정상 시작 로그는 status=ok 형태로 출력
