ABADDON v11.4.2 배포·라이브 테스트 가이드

1. 백업
- 현재 운영 봇 ZIP과 데이터 JSON을 백업합니다.
- 홈페이지 저장소의 현재 커밋을 확인합니다.

2. 봇 배포
- BOT ZIP 전체를 프로젝트 루트에 덮어씁니다.
- Render에서는 Clear build cache & deploy를 사용합니다.
- 아래 시작 로그를 확인합니다.
  [ABADDON v11.4.2] horse_odds=per_race locked_after_start=true range=1.5-9.9

3. 홈페이지 배포
- SITE ZIP 전체를 홈페이지 저장소 루트에 업로드합니다.
- / 는 한국어, /en/ 은 English인지 확인합니다.
- 버전 v11.4.2와 ONLINE 초록불을 확인합니다.

4. 집중 검수
!경마배당검수 상세
!테스트 상세
!패치노트

5. 랜덤 배당 확인
- !경마 10000을 실행하고 6마리 배당을 기록합니다.
- 선택하지 않고 새 !경마 10000 메시지를 만든 뒤 배당이 달라지는지 확인합니다.
- 한 경주가 출발한 뒤 질주 중·결과 화면의 배당이 시작 화면과 같은지 확인합니다.

6. 정산 확인
- 표시 배당 x3.7의 말에 10,000칩을 걸어 적중했다면 총 지급 37,000칩, 순손익 +27,000칩인지 확인합니다.
- 미적중 시 순손익 -10,000칩인지 확인합니다.
- 결과 화면에 이전 잔액→현재 잔액이 표시되는지 확인합니다.

7. 음수 잔액·복구
- 현재 칩보다 큰 판돈으로 경주를 진행해 패배 시 음수 잔액이 유지되는지 확인합니다.
- 테스트 환경에서 경주 중 봇을 재시작해 판돈이 자동 환불되는지 확인합니다.

8. 기존 표시 회귀
- 각 레인에 말 이름 이모지와 움직이는 ♞가 보이는지 확인합니다.
- 모든 🏁이 같은 열에 있는지 확인합니다.
