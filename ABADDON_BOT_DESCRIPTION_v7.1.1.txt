ABADDON v7.1.2 · 귀여운 인터랙션 패치

Discord 종말 생존 RPG ABADDON에 신규 멤버 새싹 표식과 전체 명령어 버튼 실행 UI를 추가했습니다.

주요 기능
- 신규 멤버에게 기본 7일간 `저 새로 들어왔어요, 환영해주세요!` 역할 부여
- 역할 아이콘 지원 서버에서 이름 옆 🌱 표시
- 입장 시 가입·정보·출석·오늘 할 일·게임·명령어 도감 환영 버튼
- !명령어 / !귀여운메뉴에서 등록된 모든 visible prefix 명령을 검색·선택·실행
- 입력이 필요한 명령은 모달 입력창으로 실행
- 잘못된 명령과 입력 오류에 귀여운 복구 버튼과 사건 번호 제공
- 버튼 실행에서도 v7.0.2 잠금·통계와 v7.1.0 성장 집계 유지

신규 이미지 파일은 추가하거나 변경하지 않았습니다.
기존 v7.1.0 성장 루프, v7.0.2 데이터 보호, v7.0.0 월드보스, v6.5.4 영어 명령어를 유지합니다.
