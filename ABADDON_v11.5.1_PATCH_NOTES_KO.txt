ABADDON v11.5.1 패치노트
서버 알림 설정 드롭다운 UI

[핵심 변경]
- !서버알림을 인자 없이 실행하면 드롭다운 설정 화면을 엽니다.
- 알림 종류, 상태/시간, 알림 채널, 멘션 역할을 한 화면에서 선택합니다.
- 적용 전 미리보기와 실제 채널 테스트 발송을 지원합니다.
- 설정 적용 전에 서버 운영 설정 복구 지점을 자동 생성합니다.
- 최근 설정 백업을 드롭다운에서 선택해 복구할 수 있습니다.
- 기존 텍스트 명령은 삭제하지 않았습니다.

[드롭다운 항목]
1. 알림 종류
   재난, 패치, 퀴즈, 암시장, 세계 이벤트, 월드보스, 챔피언십,
   연합 대항전, 경마, 스토리, 점검
2. 상태/시간
   알림 켜기, 알림 끄기, 시간 제한 없음,
   09:00~23:00 KST, 08:00~22:00 KST
3. 채널
   Discord 텍스트/공지 채널 선택 메뉴
4. 역할 멘션
   Discord 역할 선택 메뉴, 선택 해제 시 멘션 없음
   @everyone은 안전을 위해 UI에서 적용하지 않습니다.

[하단 버튼]
- 적용: 자동 백업 후 선택값 저장
- 미리보기: 저장 전 현재 선택 확인
- 테스트 발송: 선택 채널에 실제 이벤트 없는 테스트 메시지 발송
- 설정 백업: 현재 서버 운영 설정을 수동 백업
- 복구: 최근 설정 백업 선택 및 복구

[명령어]
!서버알림
!서버알림설정
!서버알림 재난 켜기 #채널
!알림시간 09:00 23:00
!알림UI검수 상세
!테스트 상세
!패치노트

English:
!serveralerts
!serveralertui
!serveralerts disaster on #channel
!alerthours 09:00 23:00
!alertuiaudit detail
!test detail
!patchnotes

[언어 정책]
- 한국어 사용자는 한국어 UI와 설명만 표시합니다.
- English 사용자는 영문 UI와 설명만 표시합니다.
- 홈페이지 / 와 /en/도 각각 최신화했습니다.

[기존 기능 유지]
- v11.5.0 서버 운영센터
- 서버별 알림 구독과 알림 시간
- 서버 봇 권한 검사
- 채널별 권한 자동 설정
- 권한 및 서버 설정 백업/복구
- 기존 텍스트 명령
