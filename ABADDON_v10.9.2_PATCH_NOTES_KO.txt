ABADDON v10.9.2 실제 적용 재패치
PNG 정보 대시보드 · 연결형 세계지도 · 카드게임 이미지 도감 · 실시간 경마 · 홈페이지 ONLINE 복구
배포일: 2026-08-03

[왜 다시 패치했는가]
이전 화면에서 !정보는 core/bot.py의 기존 텍스트 콜백을 그대로 사용했고, !세계지도는 v8.1.0의 기존 임베드 콜백을 계속 사용했습니다. 카드게임 대시보드도 상세 임베드는 있었지만 실제 PNG 첨부 화면이 최종 실행 경로에 강제 연결되지 않았습니다. 홈페이지는 config.js의 status/botInviteUrl/discordUrl 키와 script.js가 찾던 statusText/botInvite/discordInvite 키가 달라 ONLINE 표시와 링크 설정이 적용되지 않는 경로가 있었습니다.

v10.9.2는 기능을 하나 더 얹는 대신 실제 명령 객체의 최종 콜백을 모든 이전 모듈 등록 뒤에 다시 연결합니다. 따라서 이번 버전에서 !정보 또는 !세계지도에 PNG 이미지가 보이지 않거나 !경마가 없다면 서버가 이전 압축파일을 실행 중인 것입니다.

[1. 실제 PNG 정보 화면]
- !정보, !생존대시보드
- 사용자 아바타 또는 이름 이니셜
- 직업, 칭호, 레벨
- HP, 스태미나, 감염도, 상태
- 전투력, 식량, 카지노 칩, 장비 수, 펫, 던전 승리
- 카지노 칩이 음수이면 붉은색 음수 값으로 그대로 표시
- PNG 생성에 필요한 Pillow 의존성 확인
- 시스템 한글 글꼴, Noto, DejaVu, Pillow 기본 글꼴 순서의 안전 폴백

[2. 실제 PNG 공동 세계지도]
- !세계지도, !지도대시보드
- 6개 지역을 연결된 지도 형태로 표시
- 잠김/개척 중/보스 격파 상태
- 지역별 진행도와 목표, 퍼센트 게이지
- 현재 서버 환경과 위험도
- 기존 지역 정찰, 선택, 개척 기부, 거점 건설, 지역 보스 기록을 그대로 사용

[3. 카드게임 25종 실제 이미지 도감]
- !카드대시보드, !카드도감
- 포커 계열, 한국 카드·화투, 카지노·토너먼트, 파티·조합으로 분류한 PNG 도감
- 상세 종목 선택 메뉴 유지
- 종목별 규칙, 인원, 진행 방식, 일반 방 명령, 아바돈 대전 명령 표시
- 게임방 만들기, 아바돈 대전, 전체 목록 버튼 유지

[4. ABADDON 실시간 경마]
신규 명령:
- !경마 10000
- !경마장
- !경마전적
- !아바돈초대 경마 10000

영문 명령:
- !horserace 10000 / !horse 10000 / !race 10000
- !racetrack / !horsearena
- !horseracestats / !racestats
- !inviteabaddon horse 10000

규칙:
- 6마리 중 한 마리를 선택
- 모든 말의 기수는 ABADDON
- 같은 Discord 메시지에서 약 1.4초마다 말 위치와 순위가 이동
- 결승선 또는 최대 안전 틱 도달 시 우승마 판정
- 고정 배당 전액 정산
- 결과에 우승마, 내 선택, 총 지급, 이번 게임 손익, 게임 전 잔액 → 게임 후 잔액 표시
- 최소 판돈 1,000칩
- 최대 판돈 없음
- 지급 상한 없음
- 음수 잔액 허용
- 비정상 중단 시 정확한 판돈 자동 환불
- 프로세스 재시작 전에 정산하지 못한 pending 경주는 다음 시작 시 자동 환불

[5. 홈페이지 ONLINE 및 실시간 종말 기록]
- config.js와 script.js의 상태·초대 링크 키 불일치 수정
- 페이지 초기 HTML부터 ONLINE과 초록 상태등 표시
- eventFeedUrl이 비어 있어도 config의 ONLINE 정적 신호 표시
- 별도 공개 피드 API 연결 시 실제 연결 서버 수, 생존자 수, 지연시간, 마지막 신호와 공개 이벤트로 자동 전환
- live-service 폴더에 별도 Render Web Service용 표준 라이브 피드 서버 포함
- 인증된 상태/이벤트 수신과 공개 상태/이벤트 조회 지원
- 홈페이지에 실제 PNG 대시보드 미리보기 3종과 CSS 실시간 경마 애니메이션 추가

[6. 최신 명령어·설명·검수]
- 한국어 홈페이지에는 한국어 실행 명령만 표시
- English 홈페이지에는 영문 실행 명령만 표시
- 명령어 페이지와 업데이트 기록을 v10.9.2로 갱신
- !패치노트는 v10.9.2에서 실제로 바꾼 내용만 표시
- !테스트 상세는 이미지 출력, 경마, 음수 경제, 아바돈 경마, 홈페이지 피드 연결 코드만 검사
