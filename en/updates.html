MAJOR MILESTONES

The history, without the clutter.

Instead of listing every hotfix, this page keeps the releases that materially changed the player experience. Current release: v19.2.1.

v19.2.1

DASHBOARD FAST SWITCH · SNAPSHOT CACHE

Consolidated the per-server settings, structure, overview, GIF and external-alert reads into one Worker snapshot request. The 1,489-command catalogue is generated once and cached, while the overview uses a lightweight command count. Rapid server switches now cancel stale browser requests, supersede queued relay reads, and ignore old responses so they cannot overwrite the newly selected server. A 30-second browser snapshot cache makes switching back to a recent server immediate.

v19.2.0

WEB FULL CONTROL · ENGLISH PARITY · LIVE FEED

Fixed dashboard controls that could remain locked when one optional API panel timed out, restored the public real-time event feed on the official site, added a Live Feed tab inside the authenticated dashboard, expanded web-managed server/security/language/role settings, and completed a native English dashboard at /en/dashboard.html. Korean and English continue to use the same live gameplay callbacks instead of duplicated game logic.

v19.1.1

WEB DASHBOARD RELAY HOTFIX

Reworked the dashboard for Render's split Background Worker + public Web Service architecture. Discord OAuth now runs on abaddon-live-feed, while authenticated dashboard actions are relayed to the real bot Worker and written into the same world_data. This fixes the /auth/discord not_found failure.

v19.0.5

ROTATING REACTION CHOREOGRAPHY

Super Style still supports up to five reactions, but all 13 semantic categories now rotate through four curated reaction scenes. Repeated result messages no longer reuse one fixed five-reaction stack, and the concrete GIF candidate inside each category rotates as well. Re-run !giftest to see both the test theme and reaction combination change.

v19.0.4

SUPER STYLE · 5 REACTIONS

Expanded Super Style from up to three to up to five automatic custom-emoji reactions per eligible bot result. Complementary semantic categories were expanded as well, so ABADDON can actually compose five distinct reactions. The immediate !superreaction ON check and !giftest now use the five-reaction set too.

v19.0.3

SUPER REACTION RUNTIME HOTFIX

Fixed the link where !superreaction ON enabled Super Style without enabling the parent automatic-GIF runtime. Super Style now enables the runtime automatically and performs an immediate reaction check. New !gifdiag reports local/bank GIF counts, reaction permissions, external-emoji permission, and the latest Discord reaction error.

v19.0.2

ANIMATED EMOJI · SUPER STYLE

ABADDON scans custom server emojis by meaning and reacts to success, failure, combat, pets, celebrations and more. An official-server emoji bank can provide fallback emojis when an installed server has no suitable local emoji, while Super Style can combine up to three custom emoji reactions.

v19.0.1

KO/EN PARITY AUDIT HOTFIX

Fixed false-positive English alias checks, separated startup localization warm-up from real runtime fallbacks, and tightened ABADDON newcomer branding.

v19.0.1

KO/EN PARITY · ABADDON BRANDING

Korean and English now share the same live feature core, with stronger English command access and localization for buttons, dropdowns, modals and slash commands. The bright newcomer UI is also rethemed as the ABADDON quarantine network.

v19.0.1

PRESENCE ROTATION HOTFIX

Removed competing presence updates so the rotating activity text no longer goes blank between 30-second cycles.

v19.0.1

NATIVE DISCORD INTEGRATION

Connected native Discord Polls, Scheduled Events, context menus, user-install commands, forum/thread automation, Soundboard and AutoMod while simplifying toggle controls to ON/OFF.

v19.0.1

SERVER AUTOMATION · SECURITY · EXTERNAL ALERTS

Consolidated existing welcome, autorole, polls, suggestions, schedules and SERVER GUARD without duplicating them, then added giveaways, scheduled announcements, destructive-change burst alerts, and YouTube/Twitch notifications.

v18.6.0

UX / RETENTION

Added smart discovery, favorites, recents, recommendations, next-action guidance and usage telemetry so 1,400+ features are easier to find and reuse.

v18.1.0

PUBLIC LAUNCH PACK

Added seasonal PvP, weekly guild competition, referrals, optional dynamic companion AI, Discord OAuth My Page, live rankings, SQLite safety migration, policies and public-service diagnostics.

v18.0.0
