Privacy Policy

Last updated: August 15, 2026

한국어 / Korean version →

1. Data we store

  • Discord user IDs and server (guild) IDs
  • Gameplay progress, currency, equipment, quests, PvP and guild activity, and server-specific settings
  • Operational records required for command usage, error diagnosis, recovery, and service stability

2. Discord login and OAuth

My Page and the server dashboard use Discord OAuth with the identify and guilds scopes. Identity data is used to display the signed-in account, while guild metadata is used only to determine which ABADDON servers the signed-in user can manage. ABADDON does not collect Discord passwords, and OAuth access tokens are not written into gameplay save data.

3. Why we use the data

Data is used to preserve gameplay progress, display rankings and My Page, manage server settings, diagnose errors, operate the service, and recover data when necessary.

4. Retention and deletion

We retain data that is needed while the service is operating. Data-deletion requests can be submitted through the official Discord support channel. Operational and recovery backups may retain earlier records for a limited period before they are rotated or removed.

5. Third-party services

ABADDON may use Discord OAuth, optional AI providers, and Korean Discord List vote verification. When an external AI feature is enabled, messages that a user directly submits to that AI feature and a limited amount of recent conversation required for the feature may be sent to the configured AI provider. When a vote reward is verified, the Discord user ID may be used in a vote-verification API request. If an integration is disabled, the related data is not sent to that service.

6. Website sessions and dashboard relay

The ABADDON website session token is stored temporarily in the browser and normally expires after about 12 hours. Authenticated dashboard changes are relayed through the Live Feed Web Service to the Bot Worker. The Discord bot token is never sent to the browser or exposed on the public website.

7. External content alerts

If a server manager enables YouTube, Twitch, CHZZK, or SOOP alerts, ABADDON may use public channel IDs, handles, login names, or streamer IDs with the relevant public pages or platform APIs to check for new uploads or live status. API keys, client IDs, and client secrets are stored in server environment variables and are not exposed on the public website.

When member-submitted alert requests are enabled, the requester Discord ID, platform, submitted public channel identifier, review status, and reviewer ID may be stored in the server configuration.

8. Contact

For privacy questions, data-deletion requests, or service-operation questions, please use the official Discord support channel.
