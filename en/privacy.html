Privacy Policy

Last updated: 2026-08-14

Data stored

  • Discord user and guild IDs
  • Gameplay progress, currency, items, quests, PvP and guild activity
  • Operational error and recovery records

Discord login

My Page and the server dashboard use Discord OAuth scopes identify and guilds. Identity is used for the account display, while guild metadata is used only to determine which ABADDON servers the signed-in user can manage. ABADDON never collects Discord passwords, and OAuth access tokens are not written into gameplay save data.

Purpose

Data is used for persistent gameplay, rankings, My Page, service operations and recovery.

Deletion

Deletion requests can be submitted through the official Discord support channel. Backups may retain earlier records for a limited operational period.

Third parties

Optional features may connect to Discord OAuth, an AI provider, and Korean Discord List vote verification. Disabled integrations do not send data to those services.

External content alerts

If a server manager enables YouTube, Twitch, CHZZK or SOOP alerts, ABADDON may use public channel IDs, handles, login names or streamer IDs with the relevant public pages or platform APIs to check for new uploads or live status. API keys, client IDs and client secrets remain in server environment variables and are never exposed on the public website. When member alert requests are used, the requester Discord ID, platform, submitted public channel identifier, review status and reviewer ID may be stored in guild configuration data.

Website sessions & dashboard relay

The temporary ABADDON website session expires after about 12 hours. Authenticated dashboard changes are relayed through the Live Feed Web Service to the Bot Worker; the Discord bot token is never sent to the browser or public website.
