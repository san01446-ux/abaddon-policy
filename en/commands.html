🎵 ABADDON Music · Music commands

Music is played by the dedicated ABADDON Music bot. Join a voice channel and type !music play song name. repeat takes off/one/all, autoplay on keeps playing similar songs after the queue ends, and idle (1-60 min) sets how long the bot waits before leaving. Autoplay, idle time and volume need a server manager or DJ role. Invite the music bot →

🆕 Getting started · v20.5

New here? !start is all you need: buttons guide you from sign-up through tutorial rewards, and the old !first10 guide opens the same screen. !serverrank ranks servers by this week's active survivors; managers can hide their server name with !serverrankprivacy off.

☣️ Current Core · v20.5.7

Includes the 100-floor pixel roguelike, optional AI chat, opt-in personal DM alerts, and multiple named temporary-voice lobbies and sleep rooms. Server admins can install them themselves with !temp_voice_setup name · !sleeproomsetup; installed lobbies are open to everyone.

🌐 Web Dashboard · v20.5.7

Alert registration, security/log/welcome settings, GIF reactions and button roles are managed in the authenticated web dashboard. The live Command Center searches the complete public registry, while gameplay commands stay in Discord.

📡 External Stream Alerts · 4 Platforms

Server managers register and remove YouTube, Twitch, CHZZK and SOOP alerts in the web dashboard (External alerts tab). Members submit !alertrequest and staff approve it with !alertapprove. SOOP activates once SOOP_CLIENT_ID is added to the Bot Worker after API approval.

🛰️ Discord Native

Toggles use ON/OFF (the Korean 켜기/끄기 also works). Creating events and syncing schedules require staff permissions.
