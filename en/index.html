02

Current core updates

🔎

Smart discovery for unknown commands

Words like !log, !gather or !gear can open related quick buttons and a dropdown even when they are not exact commands.

⭐

Favorites & recents

Save up to 12 favorite features and reopen recent features instantly with buttons and dropdowns.

🎯

Context-aware recommendations

!recommend / !nextaction use registration, daily, tutorial, story, equipment, stamina and usage habits to suggest what to do next.

🧭

Simple persistent menu

Korean and English menus rebuild from live commands and keep features under clear top-level categories.

🛡️

Button stability

Core navigation uses stable custom IDs and persistent views to reconnect after restarts.

🚨

Automatic error watch

Unexpected internal errors are logged to SQLite and sent to the owner with duplicate suppression.

🩺

Server diagnostic

Server managers can use !serverdiag for a read-only permissions/UI/slash readiness check.

🌐

Korean / English feature parity

Korean and English use the same live command registry and callbacks, including buttons, dropdowns and modals.

🔄

30-second presence rotation

Gameplay hints and support contact rotate sequentially without random omission.

🏠

Community center

Tickets, temporary voice, button roles and server tools are consolidated into one clear entry point.

🌐

Server web dashboard

Sign in with Discord to manage server settings, GIF reactions, YouTube/Twitch/CHZZK/SOOP alerts, and the full command catalog in one place.

🎭

Button roles

Persistent role buttons let members manage notification and interest roles themselves.

🛰️

Native Discord center

!discordcenter opens native Polls, scheduled events, threads/forums, Soundboard, AutoMod and user-install features in one place.

📊

Simple polls & ON/OFF

A question is enough for a yes/no native Poll, and toggle commands now use simple ON/OFF wording.

🖱️

Context menus & user install

Open threads from message context menus, join parties from user context menus, and use /abaddon or /feature search with user-install support.

⚙️

Server automation center

Reuses welcome, autoroles, polls, suggestions and schedules while adding giveaways and scheduled announcements in one hub.

🛡️

Security command center

Keeps the existing AutoMod, anti-raid, emergency and lockdown systems and adds burst monitoring for destructive server changes.

📡

External content alerts

Server managers can announce YouTube uploads and live starts from Twitch, CHZZK and SOOP into selected Discord channels.
