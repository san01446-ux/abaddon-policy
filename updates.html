MAJOR MILESTONES

업데이트 기록도 짧게.

수십 개의 핫픽스를 모두 나열하는 대신 플레이 경험을 실제로 바꾼 주요 이정표만 남겼습니다. 현재 운영 버전은 v19.2.1입니다.

v19.2.1

DASHBOARD FAST SWITCH · SNAPSHOT CACHE

서버를 옮길 때 설정·구조·개요·GIF·외부알림을 각각 Worker에 요청하던 흐름을 스냅샷 1회 요청으로 통합했습니다. 전체 명령어 1,489개 카탈로그는 최초 1회만 생성해 캐시하고, 서버 개요에서는 빠른 카운트만 사용합니다. 연속 서버 전환 시 이전 요청과 응답이 새 서버 화면을 덮어쓰지 못하도록 취소·세대번호 보호를 추가하고, 최근 서버 화면은 30초 브라우저 캐시로 즉시 표시합니다.

v19.2.0

WEB FULL CONTROL · ENGLISH PARITY · LIVE FEED

선택형 API 하나가 지연되면 대시보드 전체가 잠기던 버튼 먹통 문제를 수정하고, 공식 홈페이지의 공개 실시간 이벤트 로그를 복구했습니다. 인증 대시보드에도 LIVE FEED 탭을 추가하고 서버 보안·언어·운영 역할 설정을 웹으로 확장했으며 /en/dashboard.html 영문 전용 대시보드를 완성했습니다. 한국어와 English는 게임 로직을 복제하지 않고 계속 같은 LIVE 콜백을 사용합니다.

v19.1.1

WEB DASHBOARD RELAY HOTFIX

Render의 Background Worker와 공개 Web Service가 분리된 구조에 맞게 대시보드 연결을 수정했습니다. Discord OAuth는 abaddon-live-feed가 처리하고, 인증된 설정 요청은 Relay Key를 통해 실제 봇 Worker가 받아 같은 world_data에 저장합니다. /auth/discord가 not_found로 끝나던 문제도 이 구조로 해결합니다.

v19.0.5

ROTATING REACTION CHOREOGRAPHY

슈퍼 스타일의 최대 5개 반응 구조는 유지하면서, 13개 의미 카테고리마다 4종 리액션 세트를 순환하도록 확장했습니다. 같은 종류의 결과가 반복되어도 고정된 5개가 계속 붙지 않으며, 각 카테고리 안의 실제 GIF 후보도 순번을 회전합니다. !GIF테스트를 반복 실행하면 테스트 주제와 조합이 함께 바뀝니다.

v19.0.4

SUPER STYLE · 5 REACTIONS

슈퍼 스타일의 자동 커스텀 이모지 반응을 메시지당 최대 3개에서 최대 5개로 확장했습니다. 각 상황의 보조 의미 카테고리도 함께 확장해 숫자만 바뀌는 것이 아니라 실제로 서로 다른 반응 5개를 조합할 수 있으며, !슈퍼반응 ON 즉시 테스트와 !GIF테스트도 5개 기준으로 동작합니다.

v19.0.3

SUPER REACTION RUNTIME HOTFIX

!슈퍼반응 ON이 슈퍼 스타일만 켜고 상위 자동 GIF 런타임을 켜지 않던 연결 오류를 수정했습니다. 이제 슈퍼반응을 켜면 자동 GIF가 함께 활성화되고 즉시 최대 3개 반응을 시험합니다. 새 !GIF진단으로 서버/뱅크 GIF 수, 반응 권한, 외부 이모지 권한과 최근 Discord 오류를 확인할 수 있습니다.

v19.0.2

ANIMATED EMOJI · SUPER STYLE

서버의 커스텀 이모지를 의미별로 스캔해 성공·실패·전투·펫·축하 같은 상황에 자동 반응합니다. 공식 ABADDON 서버를 전역 이모지 뱅크로 지정하면 설치 서버에 적절한 이모지가 없을 때 뱅크 이모지를 fallback으로 사용하며, 슈퍼 스타일은 최대 3개의 커스텀 이모지 반응을 조합합니다.
