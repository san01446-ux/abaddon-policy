ABADDON v19.0.0 · NATIVE DISCORD INTEGRATION

핵심 방향
- 기능 수는 유지하되 Discord 자체 UI와 직접 연결합니다.
- 토글형 설정은 사용자 안내를 ON/OFF로 통일합니다. 기존 켜기/끄기도 호환됩니다.
- 기존 기능을 중복 구현하지 않고 재사용/연동합니다.

신규/개편
1. !투표
   - !투표 만 입력: 투표 만들기 버튼 → 모달
   - !투표 질문: 기본 찬성/반대 Discord Poll
   - !투표 질문 | 선택1 | 선택2: 선택형 Discord Poll
2. !디스코드센터: 투표/이벤트/스레드·포럼/Soundboard/AutoMod/개인설치 안내
3. !이벤트만들기: 모달로 Discord Scheduled Event 생성
4. !일정이벤트 일정ID: 기존 ABADDON !일정 데이터를 Discord 서버 이벤트로 연동
5. 우클릭 앱
   - 메시지: 기존 메시지 요약을 ABADDON 스레드 열기로 교체
   - 유저: 기존 거래 안내를 파티 참가로 교체
   - context menu 5+5 예산을 넘기지 않도록 교체 방식 사용
6. 개인 설치형
   - /abaddon, /기능찾기 를 User Install 호환으로 등록
   - Developer Portal의 Installation에서 User Install 활성화 필요
7. !스레드자동 ON/OFF + !건의포럼 ON #포럼
8. Soundboard: !사운드보드 / !사운드추가 / !사운드재생 / !사운드삭제
9. Discord AutoMod: !디스코드자동관리 ON/OFF / !디스코드자동관리동기화
10. !알림 ON/OFF + !토글목록
11. !외부API설정안내
    - YOUTUBE_API_KEY는 YouTube URL이 아니라 Google Cloud의 YouTube Data API v3 API Key

9. !사운드보드
10. !디스코드자동관리 ON
11. !자동관리 ON / !안티레이드 ON / !알림 ON

13. !외부API설정안내
