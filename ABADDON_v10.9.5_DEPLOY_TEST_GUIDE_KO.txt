ABADDON v10.9.5 배포·실제 테스트 가이드

1. Render 또는 운영 서버에 새 봇 ZIP을 업로드합니다.
2. 이전 빌드가 남지 않도록 Clear build cache & deploy를 사용합니다.
3. 부팅 로그에서 아래 문장을 확인합니다.
   [ABADDON v10.9.5] active_turn_gif=True image_recovery=enabled replay_png=enabled live_board=card+racing spectator_image=enabled

[최신 패치 자동검사]
!테스트 상세
!연출검수 상세
!패치노트

[카드 테이블 연출]
!아바돈초대 텍사스홀덤 10000
- 진행 중 메시지가 GIF로 보이는지 확인
- 현재 차례, 단계, 최근 행동이 표시되는지 확인
- 승부 종료 후 결과 화면이 PNG인지 확인

!아바돈초대 고스톱 10000
- 공개 테이블에 손패가 노출되지 않는지 확인
- 차례와 최근 공개 행동이 갱신되는지 확인

[이미지 관전]
진행 중인 카드게임 채널에서:
!관전
!테이블정보
- 공개 카드, 팟, 현재 차례만 보이는지 확인
- 비공개 손패가 보이지 않는지 확인

[리플레이]
게임 종료 후:
!최근게임
!게임리플레이 1
!리플레이이미지 1
- 타임라인 PNG가 첨부되는지 확인
- 최종 결과가 표시되는지 확인
- 비공개 손패가 기록되지 않는지 확인

[실시간 보드]
카드게임 또는 경마 진행 중:
!실시간보드
- 진행 중 카드게임 수가 맞는지 확인
- 경마 선택마, 선두마, 틱이 갱신되는지 확인

[이미지 실패 복구 테스트]
선택 사항: 환경변수 ABADDON_ANIMATED_TABLES=0으로 재시작합니다.
- 진행 테이블이 PNG로 정상 표시되는지 확인합니다.
업로드 제한이나 일시적인 Discord 오류가 발생해도 임베드가 남고 게임이 계속되어야 합니다.

[홈페이지]
- / 한국어 메인과 /en/ English 페이지가 분리되는지 확인
- ONLINE 초록 상태등 확인
- v10.9.5 최신 문구 확인
- 새 GIF, 리플레이 PNG, 실시간 보드 미리보기 확인
- 명령어 페이지에서 !실시간보드, !리플레이이미지, !연출검수 상세 확인

[문제 발생 시]
- 부팅 로그가 v10.9.5가 아니면 이전 ZIP 또는 빌드 캐시입니다.
- GIF가 부담되면 ABADDON_ANIMATED_TABLES=0을 설정하면 PNG로 동작합니다.
- 이미지가 실패해도 턴과 정산이 유지되는지 먼저 확인하고 오류 로그를 보관하세요.
