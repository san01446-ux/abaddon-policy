ABADDON v16.3.1 배포 테스트 가이드

[1] 기본 부팅
- Python 문법 오류 없이 부팅되는지 확인합니다.
- 기존 데이터 파일을 그대로 읽는지 확인합니다.

[2] 명령어 센터
- !명령어 실행 후 5개 큰 카테고리 설명이 보이는지 확인합니다.
- 카지노 버튼을 눌러 !카지노와 포커·블랙잭·바카라·슬롯이 보이는지 확인합니다.
- 도박 버튼을 눌러 경마·탐색·주파수·룰렛·도박잔액·정부지원금이 보이는지 확인합니다.
- 명령 선택 → 설명 → 실행 버튼 흐름을 확인합니다.

[3] 신규 멤버 안내
- 테스트 계정 입장 시 환영 채널에 카테고리 설명과 8개 빠른 버튼이 보이는지 확인합니다.
- 스토리 시작·전체 명령·카지노·도박 안내 버튼을 각각 한 번 시험합니다.

[4] 정부지원금
- 잔액 -9,999: 대상 아님.
- 잔액 -10,000: +10,000 지급 후 0.
- 잔액 -300,000: +250,000 지급 후 -50,000.
- 같은 날 재신청: 24시간 쿨타임 안내.
- 지급 전후 잔액과 누적 지원 기록 확인.

[5] 채집 결과
- 일반·도시·차원·크루·동료 채집 중 가능한 경로를 시험합니다.
- 결과 카드에 이번 획득 / 수치 변화 / 누적 횟수가 표시되는지 확인합니다.
- 한글 폰트가 네모로 깨지지 않는지 확인합니다.

[6] 회귀 검사
- 기존 !카지노 직접 실행.
- 기존 !도박정보, !도박잔액, !경마.
- 시즌 1 스토리 시작·선택·기록.
- 도시 꾸미기와 자동 이모지.
