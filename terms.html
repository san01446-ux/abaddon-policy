ABADDON 이용약관

최종 수정: 2026-08-13

1. 서비스

ABADDON은 Discord에서 제공되는 게임·커뮤니티·서버 관리 기능과 관련 웹 페이지를 포함하는 서비스입니다. 기능은 운영상 필요에 따라 추가·수정·중단될 수 있습니다.

2. 이용자 책임

이용자는 Discord 이용약관과 서버 규칙을 준수해야 하며, 자동화 악용·취약점 악용·서비스 방해·타인 사칭·권한 우회 등을 해서는 안 됩니다.

3. 게임 데이터와 재화

ABADDON의 게임 재화·아이템·랭킹·보상은 서비스 내부 데이터이며 현금 가치나 환전 권리를 보장하지 않습니다. 버그·악용·운영상 오류가 확인된 경우 데이터가 복구 또는 조정될 수 있습니다.

4. 서버 관리 기능

웹 대시보드와 관리 명령은 Discord 권한을 기준으로 제공됩니다. 서버 관리자는 자동관리·로그·티켓·임시 음성·역할 등의 설정을 적용하기 전에 자신의 서버 정책과 권한 구조를 확인해야 합니다.

5. 장애와 변경

Discord, Render, 외부 API 또는 네트워크 장애로 일부 기능이 일시적으로 사용할 수 없을 수 있습니다. 운영자는 안정성·보안·정책 준수를 위해 기능을 수정할 수 있습니다.
