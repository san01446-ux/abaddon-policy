ABADDON v7.2.0 배포 및 점검 가이드

1. Render 봇 배포
- 기존 서비스 소스를 v7.2.0 봇 ZIP 내용으로 교체합니다.
- 기존 환경변수와 survival_data.json 영구 저장 경로는 유지합니다.
- 시작 로그에서 CommandRegistrationError가 없는지 확인합니다.

2. 배포 직후 관리자 점검
!시스템점검
!백업검증
!테스트 상세
!패치공지상태

3. 통합 환영 설정
!환영테마 아포칼립스
!새싹설정 환영채널
!인삿말설정 #환영 #공지 #규칙 #가입
!새싹설정 역할모드 임시
!새싹설정 기간 7
!인삿말미리보기

- 기존 !자동역할을 사용하던 서버는 해당 역할이 영구 역할 모드로 자동 이관됩니다.
- 신규 멤버 테스트 시 환영 메시지 1개, 역할 1개만 지급되는지 확인합니다.

4. 패치 자동 공지 설정
!패치채널 #업데이트
!패치자동공지 켜기
!패치공지상태
!패치공지게시

- 자동 공지는 버전당 한 번입니다.
- !패치공지게시는 관리자가 같은 버전을 수동 재게시할 수 있습니다.

5. 아바돈 AI 게임 테스트
!아바돈게임
!아바돈초대 가위바위보
!아바돈초대 포커 10000
!아바돈전적

6. 멀티 모집방 AI 테스트
!포커 10000 → 방장 혼자서 🤖 아바돈 초대
!원카드 10000 → 방장 혼자서 🤖 아바돈 초대
!조커잡기 10000 → 방장 혼자서 🤖 아바돈 초대
!생존자레이스 100000 → 참가 → 🤖 아바돈 초대 → 시작

7. 홈페이지
- 홈페이지 ZIP의 index.html, assets, script.js 등을 웹 루트에 업로드합니다.
- 캐시가 남으면 Ctrl+F5 또는 모바일 브라우저 캐시 삭제 후 확인합니다.

주의
- 봇에는 메시지 보내기, 링크 임베드, 역할 관리 권한이 필요합니다.
- 역할 지급을 사용하려면 봇 역할이 대상 역할보다 위에 있어야 합니다.
- 실제 Discord Gateway 및 Render 런타임 테스트는 배포 서버에서 최종 확인해야 합니다.
