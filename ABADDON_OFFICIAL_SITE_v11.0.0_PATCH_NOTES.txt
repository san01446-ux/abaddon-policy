- 레이즈 금액은 현재 보유 칩과 무관하게 자유 입력합니다.

- 손실이 현재 보유 칩을 넘으면 잔액은 그대로 음수가 됩니다.
- 화투 최종 배수와 정산 금액에는 별도의 잔액 상한을 다시 두지 않습니다.

- 같은 틱에 여러 말이 넘으면 해당 말들만 사진 판정 후보가 됩니다.
- 5,000회 규칙 시뮬레이션으로 위치·우승 판정을 검사했습니다.
