ABADDON v16.3.1 — 카지노·도박 탐색 및 신규 생존자 안내 핫픽스

1. !명령어 첫 화면
- 메인 RPG / 플레이 / 세계 / 소셜 / 운영에 어떤 기능이 있는지 설명을 표시합니다.
- 카지노와 도박을 바로 여는 빠른 버튼을 추가했습니다.
- 기존 검색·즐겨찾기·최근 실행·시즌 1~5 이동은 유지합니다.

2. 카지노와 도박 분리
- 카지노: !카지노, 포커·홀덤, 블랙잭, 바카라, 슬롯, VIP, 잭팟, 딜러, 카지노 상점.
- 도박: 경마, 탐색, 주파수, 생존 룰렛, 도박 잔액·기록, 파산·재기 지원.
- 맞고·고스톱·섯다·훌라·라미 등은 화투·일반 카드게임으로 유지합니다.

3. 신규 생존자 안내
- 서버 입장 환영 패널에 주요 카테고리 설명을 추가했습니다.
- 가입하기 / 스토리 시작 / 전체 명령 / 내 정보 / 오늘 할 일 / 카지노 / 도박 안내 / 초보센터 버튼을 제공합니다.
- !초보센터 명령으로 언제든 다시 확인할 수 있습니다.

4. 정부 재기 지원금
- !정부지원금 / !재기지원금 / !생존지원금.
- 보유 식량이 -10,000 이하일 때 신청할 수 있습니다.
- 24시간에 1회, 1회 최대 250,000 식량을 지급합니다.
- 지급 후 잔액이 0을 넘지 않으며 지급 전후 잔액·부채 감소·누적 지원을 기록합니다.

5. 채집 결과 개선
- 결과 이미지에 이번 획득, 소모·수치 변화, 누적 횟수, 운명 성향을 분리 표시합니다.
- 일반·도시·차원·크루·동료 채집에 같은 결과 구조를 적용했습니다.

6. 보존 정책
- 기존 명령 삭제 0건.
- 기존 카지노·도박 직접 명령과 저장 데이터 유지.
- 기존 도시 공방·이미지·자동 이모지 기능 유지.
