챗사장 추천 다음 개발 순서

1순위 — 메인 스토리 진행 추적 HUD
- 현재 시즌 / 챕터 / 마지막 선택 / 다음 목표 / 필요한 조건을 한 화면에 표시
- 「이어서 진행」 버튼 하나로 현재 스토리의 다음 명령 실행
- 스토리 진행에 따라 관련 기능을 순차 해금·추천
- 신규 사용자가 1,343개 명령을 처음부터 전부 볼 필요가 없도록 발견형 UI 제공

2순위 — 도시 편집기 2.0
- 이미 배치한 부품 선택·이동·삭제·회전
- 레이어 앞으로/뒤로, 격자 맞춤, 복사, 다중 선택
- 구역별 프리셋 저장과 도시 배치 공유 코드
- 작업 타임라인 20단계 되돌리기/다시 실행

3순위 — 상황별 다음 행동 버튼
- 전투 종료: 다시 전투 / 회복 / 장비 / 다음 스토리
- 채집 종료: 다시 채집 / 가방 / 제작 / 판매
- 도시 행동: 도시지도 / 공방 / 거래소 / 오늘의신문
- 스토리 장면: 선택 / 기록 / 인물 / 다음 장면

4순위 — 실사용 기반 명령 건강검진
- 실제 사용 횟수, 오류율, 평균 응답시간, 버튼 실패, 이미지 생성 실패 기록
- 중복 명령과 접근 불가능 명령을 자동 표시하되 삭제는 운영자 승인 후 진행
- 1,343개 명령의 카테고리 오분류를 관리자 버튼으로 즉시 수정

5순위 — 선택이 세계를 바꾸는 연동
- 시즌 스토리 선택이 BLACK CITY 치안·경제·NPC 관계·세력전에 실제 반영
- 도시 사건과 차원 탐사의 결과가 개인 연대기와 서버 엔딩에 누적
- 서버별 서로 다른 역사와 결말 생성
