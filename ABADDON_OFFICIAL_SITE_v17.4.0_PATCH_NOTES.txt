ABADDON v17.4.0 — SYSTEM FUSION
배포일: 2026-08-06

[핵심 방향]
기능을 삭제하거나 새 복제품을 만드는 대신, 기존 스토리·세계·원정·NPC·제작·도시 기능을 몇 개의 핵심 허브로 연결했습니다.

[1. 생존단말기]
- 기존 !단말기 / !생존단말기 진입점을 v17.4 통합 화면으로 갱신
- 현재 스토리, 오늘의 세계 사건, 최고 위험 지역, 진행 중 의뢰, NPC 인연, 도시 효과 표시
- 스토리 계속, 의뢰소, 솔로 원정, 생산센터, NPC 인연 버튼 제공
- 기존 !생존허브, !연결허브와 저장 데이터는 그대로 유지

[2. 생존 의뢰소]
- !의뢰소: 세계 상태 기반 일일 의뢰 3개 + 주간 의뢰 1개
- !의뢰수락 번호: 최대 3개 동시 진행
- !의뢰진행: 기존 세계 사건·원정·NPC 동행·도시 공방·재료·경제 상태를 읽어 자동 판정
- !의뢰포기 번호, !의뢰기록 지원
- 기존 납품 계약은 !계약수락 / !납품계약으로 보존

[3. 세력 평판]
- 생존자 연합
- BLACK CITY 공방회
- 암시장 상인회
- NEON ABYSS 관측단
- 검은 태양 교단
- 의뢰 완료 시 평판, 관련 NPC 신뢰·호감, 살아 있는 세계 지표를 함께 갱신
- 기존 !평판 / !세력평판 진입점을 v17.4 통합 평판 화면으로 갱신

[4. 생산센터]
- !생산센터
- 채집 → 가방 → 제작 → 재료 사용처 → 도시 배치 버튼 흐름
- 주요 재료 보유량과 현재 도시 효과 표시
- 기존 채집·가방·제작·도시꾸미기 명령은 그대로 실행

[5. 명령어 허브]
- 상위 5개 영역 유지
- 신규 기능군: 생존단말기·통합 허브 / 생존 의뢰소 / 생산센터
- 빠른 버튼 7페이지 추가
- 생존단말기 / 의뢰소 / 생산센터 / 세력 평판 바로가기
- 한국어와 English 화면은 동시에 섞이지 않음

[6. 결과 가시화]
의뢰 완료 결과에 다음을 통합 표시합니다.
- 획득 식량·EXP
- 잔액·EXP 전후
- 세력 평판 전후
- 관련 NPC 관계 변화
- 살아 있는 세계 지표 변화
- 다음 행동 버튼

[보존]
- 기존 명령 삭제 0건
- 기존 저장 데이터 삭제 0건
- 시즌 1~6, 살아 있는 세계, 솔로 원정, NPC 인연, 도시 공방, 카지노, 도박 유지
- 외부 플랫폼·오픈소스·제3자 자산의 권리는 각 권리자에게 있음
