ABADDON v7.3.0 배포·테스트 가이드

1. Render 서비스의 기존 소스를 ABADDON_BOT_v7.3.0_SEASON_STORY_WAGER_PATCH.zip 내용으로 교체합니다.
2. requirements.txt와 apocalypse_bot 폴더가 저장소 루트에 위치하는지 확인합니다.
3. 배포 전 기존 survival_data.json 백업을 보관합니다.
4. Render 로그에서 CommandRegistrationError 또는 Traceback이 없는지 확인합니다.

[필수 스모크 테스트]
!시스템점검
!백업검증
!테스트 상세
!패치노트
!시즌4
!시즌4 시작
!시즌여정
!시즌유산

[AI 베팅 테스트]
※ 실제 돈이 아닌 게임 내 카지노 칩/식량만 사용합니다.
1) !아바돈게임 1000
   - 기존 문법으로 칩 1,000 참가비가 표시되는지 확인
2) !아바돈게임 식량 5000
   - 식량 5,000 참가비가 표시되는지 확인
3) !아바돈내기 홀짝 칩 1000
4) !아바돈내기 가위바위보 식량 5000
5) 무승부 또는 시간초과 시 원금이 환급되는지 확인
6) 결과 버튼을 빠르게 여러 번 눌러도 한 번만 정산되는지 확인
7) !아바돈전적에서 칩/식량 베팅 기록이 분리 표시되는지 확인

[홈페이지]
- ABADDON_OFFICIAL_SITE_v7.3.0_UPLOAD.zip을 홈페이지 루트에 업로드합니다.
- 브라우저 강력 새로고침(Ctrl+F5)을 수행합니다.
- 최신 버전 v7.3.0, 시즌 4 섹션, 신규 명령어 검색을 확인합니다.

실제 Discord Gateway·권한·네트워크 환경은 배포 서버에서 최종 확인해야 합니다.
