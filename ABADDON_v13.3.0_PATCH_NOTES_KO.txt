ABADDON v13.3.0 — 명령 등록 충돌 긴급 안정화 패치
패치일: 2026-08-05

[원인]
Render 로그에서 v1220_chaos_festival_complete.py의 `탐험` 명령이 `expedition` 별칭을 등록하려 했지만, 기존 `원정` 명령이 이미 같은 별칭을 사용 중이라 CommandRegistrationError가 발생했습니다. 오류가 import 단계에서 발생해 Discord 접속 전에 프로세스가 종료됐습니다.

[수정]
- 기존 `!expedition`은 기존 `!원정`에 그대로 유지합니다.
- 혼돈의 축제 `!탐험` 영문 접근은 `!festivalexpedition`, `!chaosadventure`로 분리했습니다.
- 같은 방식으로 충돌 가능성이 있던 `fortune`, `checkin`, `marketbuy`도 신규 기능 전용 별칭으로 분리했습니다.
- 봇 생성 직후 명령 등록 보호기를 설치했습니다.
- 별칭 충돌 시 기존 명령을 보존하고 충돌 별칭만 제거한 뒤 부팅을 계속합니다.
- 명령 이름 자체가 충돌하면 새 명령만 격리하고 파일·줄·충돌 이름을 로그에 남깁니다.
- `!명령등록검수 상세`, `!1330안정화검수 상세`를 추가했습니다.

[데이터]
BLACK CITY, 혼돈의 축제, 카드게임, 화투, 포커, 경마와 기존 저장 데이터 구조는 변경하지 않습니다.
