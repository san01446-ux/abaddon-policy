ABADDON v11.5.1 배포·테스트 가이드

1. 배포
- ABADDON_BOT_v11.5.1_ALERT_SETTINGS_DROPDOWN_AUDITED_PATCH.zip을 배포합니다.
- Render에서는 Clear build cache & deploy를 권장합니다.
- 다음 부팅 로그를 확인합니다.
  [ABADDON v11.5.1] alert_settings=dropdown channel_select=enabled role_select=enabled backup_restore=enabled text_commands=kept

2. 변경 없는 검수
!테스트 상세
!알림UI검수 상세
!패치노트

3. 드롭다운 기본 흐름
- 관리자 계정으로 !서버알림 실행
- 알림 종류 선택
- 알림 켜기 또는 끄기 선택
- 텍스트/공지 채널 선택
- 역할 멘션 선택 또는 선택 해제
- 미리보기 버튼 확인
- 테스트 발송 버튼 확인
- 적용 버튼 실행

4. 저장 확인
!서버운영
!서버알림 재난
!알림테스트 재난

5. 백업·복구 확인
- !서버알림 화면에서 설정 백업 버튼 실행
- 설정을 한 번 변경 후 적용
- 복구 버튼에서 이전 복구 ID 선택
- 선택 백업 복구 버튼 실행
- !서버운영에서 원래 설정인지 확인

6. 기존 텍스트 명령 회귀
!서버알림 재난 켜기 #재난알림
!서버알림 재난 끄기
!알림시간 09:00 23:00
!알림시간해제

7. 안전 확인
- 일반 사용자가 드롭다운을 조작할 수 없는지 확인
- 다른 관리자가 아닌 실행자만 열린 UI를 사용할 수 있는지 확인
- @everyone 역할 선택 시 적용되지 않는지 확인
- 봇 권한이 없는 채널의 테스트 발송이 안전하게 실패하는지 확인
- 10분 뒤 UI 버튼과 선택 메뉴가 비활성화되는지 확인

8. 홈페이지
- 한국어 /에서 v11.5.1 확인
- English /en/에서 v11.5.1 확인
- 명령어 및 업데이트 페이지 확인
- 한국어/English 문구가 섞이지 않는지 확인
