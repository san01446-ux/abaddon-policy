ABADDON v12.2.0 배포·실제 서버 테스트 가이드

1. 기존 배포 폴더와 데이터 파일을 통째로 백업합니다.
2. BOT ZIP의 내용을 기존 앱 루트에 덮어씁니다. 데이터베이스·환경 변수·Discord 토큰은 삭제하지 않습니다.
3. requirements.txt 기준 의존성을 설치하고 앱을 재시작합니다.
4. 부팅 로그에서 다음 문장을 확인합니다.
   [ABADDON v12.2.0] chaos_events=8 party_games=6 npc=6 pets=8 expeditions=8 businesses=8 social=safe cosmetics=enabled secrets=discoverable auto=opt-in rollback=enabled
5. 먼저 변경 없는 검수 명령을 실행합니다.
   !테스트 상세
   !1220통합검수 상세
   !패치노트
6. 테스트 서버에서 아래 흐름을 확인합니다.
   !혼돈축제
   !돌발이벤트 시작 운석
   !이벤트참가 공격
   !파티게임
   !폭탄돌리기
   !폭탄참가
   !탐험 폐허
   !탐험선택 정찰
   !동료뽑기
   !사업개설 카페
   !서버빙고
7. 자동 돌발 이벤트는 기본 꺼짐입니다. 실제 운영에 사용할 서버에서만 관리자가 !이벤트설정으로 켭니다.
8. 익명 응원은 기본 꺼짐입니다. 관리자 감사·신고 정책을 확인한 뒤 !친목설정에서 허용합니다.
9. 설정 변경 전 !혼돈백업을 실행하고 표시된 FBK 복구 ID를 보관합니다.
10. 문제가 생기면 !혼돈복구 [백업ID]로 축제 설정·진행 데이터를 되돌립니다.

필수 실제 테스트
- 관리자/일반 사용자 권한 분리
- 한국어 선택 계정과 English 선택 계정의 화면 분리
- 마피아·라이어·비밀친구 개인 메시지 수신
- 두 명 이상 동시 참가와 투표
- 탐험 진행 중 앱 재시작 후 상태 유지
- 이벤트 보상 명령 반복 시 중복 지급 차단
- 자동 이벤트가 구독하지 않은 서버에 게시되지 않는지 확인
- 익명 응원 URL·@everyone 차단과 신고 로그 확인
- 백업 생성 후 설정 변경·복구 확인

제작 환경에서는 Discord 토큰과 Gateway 연결을 사용할 수 없어 실제 버튼 동시 클릭, 개인 메시지 전달, 예약 시간 대기와 채널 권한 동작은 실행하지 못했습니다. 운영 서버 배포 전에 별도 테스트 서버에서 위 항목을 확인해야 합니다.
