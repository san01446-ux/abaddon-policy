⭐

즐겨찾기·최근

자주 쓰는 기능은 최대 12개까지 저장하고, 최근 사용 기능도 버튼과 드롭다운으로 바로 다시 실행합니다.

🎯

상태 기반 추천

가입·출석·튜토리얼·스토리·장비·스태미나와 사용 습관을 보고 !추천 / !다음할일이 다음 행동을 제시합니다.

🧭

쉬운 영구 메뉴

한국어·영어 모두 실제 등록 명령을 다시 읽고 최상위 카테고리 아래 자동 정리합니다.

🛡️

버튼 안정화

핵심 메뉴는 고정 custom_id와 Persistent View로 재시작 이후에도 다시 연결됩니다.

🚨

자동 오류 감시

실제 내부 오류는 SQLite에 기록하고 제작자에게 중복 억제 DM을 보냅니다.

🩺

서버 진단

서버 관리자가 !서버진단으로 메시지·임베드·파일·UI·슬래시 준비 상태를 읽기 전용 점검합니다.

🌐

한·영 동일 기능 코어

한국어와 English가 같은 LIVE 명령 레지스트리와 같은 기능 콜백을 사용하고 버튼·드롭다운·모달까지 동일 구조로 연결합니다.

🔄

30초 상태 순환

게임 기능과 장애 문의 안내가 랜덤 누락 없이 순서대로 자동 순환합니다.

🏠

커뮤니티 센터

문의·임시 음성방·버튼 역할·운영 기능을 한곳에서 찾을 수 있게 통합했습니다.

🌐

서버 웹 대시보드

Discord 로그인 후 서버 설정·GIF 자동반응·YouTube/Twitch/치지직/SOOP 알림·전체 명령어 검색을 한 화면에서 관리할 수 있습니다.

🎭

버튼 역할

재시작 후에도 살아있는 역할 선택 버튼으로 알림·관심 역할을 사용자가 직접 관리합니다.

🛰️

Discord 네이티브 센터

!디스코드센터에서 Discord 기본 Poll·서버 이벤트·스레드/포럼·Soundboard·AutoMod·개인 설치 기능을 한곳에서 엽니다.

📊

간단 투표·ON/OFF

!투표 질문만 입력하면 찬성/반대 기본 Poll이 생성되고, 토글 설정은 !자동관리 ON · !알림 OFF처럼 통일했습니다.

🖱️

우클릭·개인 설치

메시지 우클릭으로 스레드를 열고 유저 우클릭으로 파티에 참가할 수 있으며 /abaddon · /기능찾기는 User Install 호환으로 준비했습니다.

⚙️

서버 자동화 센터

기존 환영·자동역할·투표·건의·일정을 재사용하고, 경품 추첨과 자유문구 예약 공지를 한 화면에 연결합니다.

🛡️

보안 지휘센터

기존 AutoMod·안티레이드·비상모드·서버잠금을 그대로 살리고 채널/역할 삭제·웹훅 변경 폭주 감시를 추가했습니다.

📡

외부 콘텐츠 알림

서버 관리자가 YouTube 새 영상과 Twitch·치지직·SOOP 방송 시작을 원하는 Discord 채널에 자동 공지할 수 있습니다.

🚘

FiveM 인생서버 양방향 연동

ABADDON 릴레이로 Discord와 QBCore를 안전하게 연결해 상태·캐릭터·자금·직업·아이템·소유차량·공지·소생/퇴장·이벤트 로그·근무 역할 동기화를 지원합니다. 게임 DB 비밀번호는 Discord 봇에 저장하지 않습니다.
