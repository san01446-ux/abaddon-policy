ABADDON v16.8.0 — LONE SURVIVOR

혼자서도 끝까지 이어지는 개인 로그라이크 생존 원정 패치입니다.
기존 시즌·장비·채집·제작·도시 공방·개인 전설 데이터를 삭제하거나 대체하지 않고 하나의 솔로 플레이 루프로 연결합니다.

[핵심 기능]
- 6~9단계 버튼형 개인 원정: 이동, 사건, 전투, 수색, 보급 판단, 보스, 귀환
- 지역 7종: 시즌 1~5, BLACK CITY, NEON ABYSS
- 난이도 4종: 생존자, 베테랑, 악몽, 심연
- NPC 동료 5종: 정찰병, 의무병, 기술자, 중화기병, 교섭가 중 최대 2명 편성
- 주간 변이 지역과 피해·보상 보정
- 4~12자 씨앗 코드로 같은 조건 재도전
- 행동마다 중도 저장, 봇 재시작 뒤 이어하기
- 완전 사망 대신 긴급 구조와 난이도별 부분 보상
- 사건·적·NPC·유물·도시 설계도·결말 원정 도감
- 완주·철수·구조·최고 점수·최근 씨앗 기록
- 결과 화면에 획득, 소모, HP·감염·사기 변화, 새 기록과 다음 행동 표시
- 기존 도시 부품 ID와 호환되는 설계도 보상

[명령어 센터]
- !명령어 → 메인 RPG → 탐험·원정에서 솔로 원정 기능 확인
- 빠른 버튼 3페이지: 솔로 원정 / 주간 변이 / 원정 도감 / 원정 기록 / 기본 메뉴
- 한국어 선택은 한국어 UI만, English 선택은 English-only UI만 표시
