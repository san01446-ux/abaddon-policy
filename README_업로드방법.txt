ABADDON 공식 홈페이지 v4.0.5 업로드 방법

공식 주소는 그대로 유지됩니다.
https://san01446-ux.github.io/abaddon-policy/

1. 압축을 풉니다.
2. config.js를 메모장으로 엽니다.
3. YOUR_APPLICATION_ID를 Discord Developer Portal의 Application ID로 바꿉니다. 기존에 사용 중인 봇 초대 URL이 있다면 config.js의 botInviteUrl 전체를 그 주소로 바꿔도 됩니다.
4. YOUR_PERMANENT_INVITE를 아바돈 공식 서버의 만료 없는 초대 코드로 바꿉니다.
5. 이 폴더 안의 파일 전체와 assets 폴더를 기존 abaddon-policy GitHub 저장소 최상위에 덮어씁니다.
6. GitHub의 Commit changes를 누릅니다.
7. 보통 1~3분 뒤 기존 공식 주소에 최신 홈페이지가 표시됩니다.

중요
- ZIP 파일 자체를 올리지 말고 압축을 푼 파일을 올리세요.
- 기존 GitHub Pages 주소는 변경할 필요가 없습니다.
- terms.html과 privacy.html 주소도 그대로 유지됩니다.
- 기존 config.js에 이미 실제 봇 초대 주소와 서버 초대 주소를 넣어뒀다면, 새 config.js에 같은 값을 옮겨 적으세요.
