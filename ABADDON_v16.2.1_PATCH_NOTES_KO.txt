ABADDON v16.2.1 — 이미지·명령어 UI·홈페이지 핫픽스

[정보 이미지 한글 폰트 복구]
- Pillow 기반 이미지 렌더러 6개 모듈을 공통 한글 글꼴 탐색기로 연결했습니다.
- 서버에 한글 글꼴이 있으면 Nanum/Noto/UnDotum 계열을 우선 사용합니다.
- 서버에 한글 글꼴이 없으면 Noto Sans CJK KR을 /tmp 캐시에 확보한 뒤 사용합니다.
- DejaVu 기본 글꼴로 한글을 억지 출력해 네모 문자로 보이는 경로를 피합니다.
- 이미지 안의 이모지 텍스트 의존도를 줄이고 도형 아이콘으로 교체했습니다.

[오류 이미지 재제작]
- !채집 결과 PNG를 실제 모드·결과·누적·운명 값으로 다시 렌더링합니다.
- !꾸미기센터의 ABADDON CHAOS PROFILE을 사용자별 실제 통계와 칭호로 다시 렌더링합니다.
- !돈주세요 결과를 실제 획득량·잔액·남은 횟수·상황이 반영된 정보 카드 이미지로 교체했습니다.
- 이미지 생성 또는 Discord 첨부 편집이 실패하면 기존 임베드 결과로 안전하게 복구합니다.
- 고퀄리티 샘플 이미지와 런타임 미리보기를 v1621 자산 폴더에 포함했습니다.

[!명령어 구조 축소]
- 기존 24개 단위 대형 드롭다운 대신 큰 영역 → 세부 그룹 → 기능의 3단계 흐름으로 줄였습니다.
- 5개 큰 영역: 시작 / 플레이 / 세계 / 소셜 / 운영.
- 세부 그룹 드롭다운과 기능 드롭다운을 분리해 처음 보는 사용자의 혼란을 줄였습니다.
- 모든 세부 그룹과 기능 선택지에 한 줄 설명을 표시합니다.
- 대표/전체, 이전/다음, 검색 안내는 한 줄의 최소 버튼으로 정리했습니다.
- 기존 명령어와 카테고리, 저장 데이터는 삭제하지 않았습니다.

[홈페이지 길이 개선]

- 탈것 도감 8종 이미지를 v16.2.1 기준으로 다시 제작했습니다.
