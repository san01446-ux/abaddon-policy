ABADDON v7.6.0 — 길드 협동 파견 · 안전 정산 패치
패치 날짜: 2026-08-03

[실서버 확인]
- v7.5.1은 사용자 Render 환경에서 게임센터 등록, Discord Gateway 연결, 로그인까지 정상 완료되었습니다.
- 시작 로그의 guild migration guilds=0은 길드가 아직 없을 때 검사 대상이 0개였다는 상태 정보이며 오류가 아닙니다.
- v7.6.0에서는 파견 시작 로그에 status=ok를 명시해 길드 0개 상태도 오류처럼 보이지 않게 했습니다.

[신규: 길드 협동 파견]
길드원이 역할을 나눠 비동기 파견대를 편성합니다. 개인 원정과 달리 길드 금고를 사용하고, 참가자 전투력을 출발 시점에 저장해 결과를 계산합니다.

파견 지역 4종
1. 폐허 보급로 — 10분 · 권장 전투력 220 · 식량/나무/고철
2. 침수 산업지대 — 30분 · 권장 전투력 650 · 식량/광석/고철
3. 격리연구소 외곽 — 1시간 · 권장 전투력 1,400 · 약초/고철/전술 데이터
4. 황혼 철도 종착지 — 2시간 · 권장 전투력 2,800 · 고급 길드 자원/길드훈장

역할 4종
- 선봉: 개인 전투력 보정이 가장 높습니다.
- 기술: 장비·설비 대응에 유리한 전투력 보정을 받습니다.
- 의무: 실패 시 보상 손실을 일부 줄입니다.
- 보급: 성공 보상량을 추가로 높입니다.
- 서로 다른 역할이 모이면 역할 다양성 보너스가 적용됩니다.

[안전 정산]
- 모집·참가·출발·정산·보상 수령은 길드별 동일 잠금을 사용합니다.
- 출발 비용은 잔액 확인과 차감을 같은 잠금 안에서 처리합니다.
- 파견마다 고유 ID를 생성합니다.
- 길드 공동 보상은 파견 결과를 최초 정산할 때 한 번만 지급됩니다.
- 개인 보상은 파견ID:사용자ID claim key로 중복 수령을 막습니다.
- 두 사용자가 동시에 정산하거나 같은 사용자가 보상 버튼을 연속 실행해도 한 번만 반영됩니다.
- 창고 보관 한도를 넘는 보상은 초과량을 결과에 표시합니다.
- 완료 기록과 보상 감사 기록은 자동 삭제하지 않습니다.

[무변경 모의 계산]
!길드파견모의 지역 역할은 길드 상태의 복사본과 현재 전투력만 사용합니다.
길드 금고, 파견 기록, 보상, 캐릭터 재화, 쿨다운은 변경하지 않습니다.
