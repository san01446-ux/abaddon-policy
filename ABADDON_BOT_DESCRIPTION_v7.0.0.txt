ABADDON v7.0.0 — Bot Description / 봇 설명

[한국어]
ABADDON은 Discord에서 즐기는 종말 생존 RPG 봇입니다. 성장, 스토리, 던전, 월드보스, 장비, 보물, 펫, 기지, 생활, 거래, 카드게임과 서버 관리 기능을 제공합니다.

v7.0.0에서는 월드보스 시스템을 전면 리빌드했습니다. 새 보스가 출현해도 처치 보상이 사라지지 않는 길드별 보상 큐를 적용했고, 실전 전투와 테스트 전투를 완전히 분리했습니다. 보스 6종의 약점, 네 단계 페이즈, 부위 파괴, 회피와 실제 반격이 전투 계산에 적용됩니다. 월드보스 및 이벤트 배너 이미지 10종도 신규 고품질 아트로 교체했습니다.

기존 한국어 명령어와 v6.5.4 영어 prefix 별칭은 그대로 유지되며 같은 쿨타임, 권한, 저장 데이터를 사용합니다.

[English]
ABADDON is a post-apocalyptic survival RPG bot for Discord with progression, story campaigns, dungeons, world bosses, equipment, treasures, pets, bases, gathering, trading, card games, and server management.

Version 7.0.0 rebuilds the world-boss system with a persistent completed-battle reward queue, separate live and sandbox test battles, real boss weakness modifiers, four combat phases, differentiated breakable parts, evasion, and real counterattack consequences. Ten world-boss and event banner artworks have also been replaced with new high-quality key art.

Existing Korean commands and the v6.5.4 English prefix aliases remain available and share the same cooldowns, permissions, and saved progress.
