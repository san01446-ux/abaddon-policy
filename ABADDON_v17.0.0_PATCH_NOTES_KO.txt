ABADDON v17.0.0 — BLACK SUN CREATOR ERA

1. 런타임 전면 청소
- 버튼 실행에서 discord.py MISSING 값을 실제 Cog로 오인하던 경로를 실제 commands.Cog 판정으로 교체했습니다.
- Interaction follow-up Webhook이 지원하지 않는 delete_after를 직접 넘기지 않고, 전송 후 안전한 예약 삭제로 전환했습니다.
- 성장 집계에서 사용자 데이터가 None인 경우 .get 호출로 이어지지 않도록 차단했습니다.
- 같은 명령 실패 안내가 짧은 시간에 중복 전송되는 현상을 억제했습니다.

2. 콘텐츠 제작 공방
- !콘텐츠공방에서 관리자·봇 소유자가 한국어와 English 제목·설명·결과를 따로 입력합니다.
- 선택지는 2~5개이며 각 선택에 식량·EXP·HP·감염·재료 변화를 설정할 수 있습니다.
- 미리보기와 테스트 모드는 실제 보상을 지급하지 않습니다.
- 공개된 사건은 !콘텐츠목록 또는 !사용자사건에서 플레이합니다.
- 사용자별·사건별 보상은 한 번만 정산합니다.

3. 시즌 6 — 검은 태양의 귀환
- 5개 장의 서버 공동 스토리를 추가했습니다.
- 각 장의 3개 선택지에 투표하고 관리자가 최다 득표 결과를 확정합니다.
- 희망·질서·생존·심연 지표가 선택에 따라 변화합니다.
- 지표 조합에 따라 새벽의 귀환, 영원의 봉인도시, 최후의 요새, 심연의 왕도, 검은 태양 협정 결말이 기록됩니다.
- 참여자는 완료 후 식량 150,000, EXP 500, 전용 칭호를 한 번 수령합니다.

4. 명령어 센터
- 메인 RPG에 시즌 6 기능군을 추가했습니다.
- 빠른 버튼 4페이지에 시즌 6, 콘텐츠 공방, 사용자 사건, v17 점검을 연결했습니다.
- 시즌 이동 표기를 시즌 1→6으로 최신화했습니다.
- 한국어 선택은 한국어만, English 선택은 English-only 화면만 표시합니다.

5. 비공개 소유권 금고
- 일반 사용자 화면에 노출되지 않는 ABADDON_OWNER_PROOF.json과 비공개 저작권 고지를 포함했습니다.
- !권리증명은 봇 소유자만 사용할 수 있습니다.

기존 기능·명령·저장 데이터 삭제 0건.
