ABADDON v7.2.0 — 통합 환영 · 패치 자동 공지 · 아바돈 동료전
패치 일자: 2026-08-03

[1] 신규 멤버 시스템 통합
- 기존 SERVER GUARD 환영 안내와 v7.1.x 테마형 환영 패널을 하나의 입장 이벤트로 통합했습니다.
- 신규 멤버 입장 시 환영 카드는 정확히 1개만 전송됩니다.
- 공지·규칙·가입 채널, 선택한 환영 테마, 빠른 시작 버튼을 한 카드에 표시합니다.
- 기존 !환영채널, !인삿말설정, !자동역할 설정은 새 통합 설정으로 자동 이관됩니다.

[2] 신규 역할 통합
- 기존 자동 역할과 새싹 역할을 하나의 role_id 설정으로 통합했습니다.
- 임시 모드는 설정 기간이 지나면 역할을 자동 제거합니다.
- 영구 모드는 서버 기본 자동 역할을 계속 유지합니다.
- 역할 지급을 끄더라도 환영 카드만 사용할 수 있습니다.

[3] 패치 자동 공지
- !패치채널 [#채널]
- !패치자동공지 켜기/끄기
- !패치공지상태
- !패치공지게시
- 새 버전은 지정 채널에 버전당 한 번만 게시됩니다.
- Render 재연결이나 on_ready 중복 호출에도 같은 버전이 반복 게시되지 않도록 잠금을 적용했습니다.

[4] 아바돈 AI 동료전
- !아바돈게임 [참가비]
- !아바돈초대 게임이름 [참가비]
- !아바돈전적
- 가위바위보, 홀짝, 숫자결투, 포커, 간편 원카드, 조커 추적, 신호 예측 7종을 제공합니다.
- 무료 친선전 또는 카지노 칩 참가비를 선택할 수 있습니다.
- 시간 초과와 시작 실패 시 참가비를 환불합니다.

[5] 멀티 미니게임 AI 초대
- 포커·원카드·조커잡기 모집방에서 방장이 혼자일 때 아바돈을 초대할 수 있습니다.
- 생존자 레이스에서도 인간 1명 + 아바돈으로 시작할 수 있습니다.
- 레이스 최대 인원은 아바돈을 포함해 8명으로 제한됩니다.

[6] 안정화 검수
- !데이터백업 / !백업생성 명령 별칭 충돌 수정 상태 유지
- 신규 최상위 명령어·별칭 충돌 검사
- 환영 메시지·역할 처리 리스너 단일화 검사
- Discord 버튼 5개/행, 드롭다운 25개 제한 검사
- AI 참가비 차감·승패 정산·시간 초과 환불 경로 점검
- Python 정적 컴파일, 홈페이지 JavaScript 문법, 로컬 링크, ZIP 구조 검사
- 기존 이미지 변경 없음
