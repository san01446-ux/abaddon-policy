[스토리 시즌 4]
- 신규 선택형 캠페인 「황혼의 종착역」 추가
- 6개 장면, 4개 엔딩, 드롭다운 선택 UI
- 시즌 1~4 완료 및 엔딩 수집 현황: !시즌여정
- 시즌 4 엔딩 수집 단계 보상: !시즌유산
- 엔딩과 이미 받은 선택 보상을 보존한 재시작 지원

[아바돈 1:1 선택 베팅]
- 실제 돈이나 현금 결제 없이 게임 내 카지노 칩 또는 식량만 사용
- 기존 카지노 칩 참가비 유지
- 게임 내 식량 베팅 추가
- 기존 문법 호환: !아바돈게임 1000 = 칩 1,000
- 신규 문법: !아바돈게임 식량 5000
- 직접 지정: !아바돈내기 포커 칩 1000
- 일반 게임 총지급 2배, 숫자결투 5배, 신호예측 4배
- 무승부 및 시간초과 원금 환급
- 게임 시작 메시지 전송 실패 시 자동 환급
- 정산 잠금으로 중복 클릭·동시 완료 중복 지급 차단
- 아바돈전적에 칩/식량 누적 베팅·회수·순손익 표시
