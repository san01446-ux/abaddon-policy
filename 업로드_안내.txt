ABADDON 공식 홈페이지 v4.2.3 수정 업로드 안내

[왜 수정됐나요?]
이전 v4.2.1~v4.2.3 홈페이지 ZIP이 테스트용 빈 홈페이지를 기준으로 생성되어
CSS와 페이지 구조가 거의 없는 상태였습니다. 이 ZIP은 완전한 정적 홈페이지 파일입니다.

[업로드 방법]
1. 이 ZIP을 압축 해제합니다.
2. 안의 index.html, commands.html, updates.html, style.css, script.js, config.js를
   GitHub Pages 저장소의 최상위(루트)에 그대로 덮어씁니다.
3. ZIP을 폴더째 올리지 말고, 파일 6개가 저장소 첫 화면에 직접 보여야 합니다.
4. 커밋 후 GitHub Pages 배포가 끝나면 브라우저에서 Ctrl+F5로 강력 새로고침합니다.

[확인할 것]
- 메인 화면에 v4.2.3 표시
- 검정/적색 계열 디자인 정상 표시
- 명령어 페이지 검색과 필터 정상 작동
- 업데이트 페이지에서 v4.2.3이 LATEST로 표시

이 파일은 홈페이지용이며 Discord 봇 저장소에는 업로드하지 마세요.
