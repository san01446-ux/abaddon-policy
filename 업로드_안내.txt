ABADDON 공식 홈페이지 v4.3.2 업로드 안내
========================================

1. 이 ZIP을 압축 해제합니다.
2. 아래 파일을 GitHub Pages 홈페이지 저장소 최상위 루트에 직접 덮어씁니다.
   index.html
   commands.html
   updates.html
   style.css
   script.js
   config.js
3. 폴더째 한 단계 아래에 넣지 마세요. 저장소 첫 화면에 위 파일이 직접 보여야 합니다.
4. 커밋 후 GitHub Pages 배포가 끝나면 Ctrl+F5 또는 모바일 브라우저 캐시 삭제 후 확인합니다.

[실시간 피드 연결 — 필수 1줄]
config.js를 열어 다음 값을 본인의 Render 공개 봇 주소로 바꿉니다.

  eventFeedUrl: "https://본인의-Render-서비스주소.onrender.com",

봇 Render 환경변수 PUBLIC_BASE_URL도 같은 주소여야 합니다.
주소를 비워두면 홈페이지 디자인·명령어·업데이트 페이지는 정상 작동하고,
실시간 패널만 "연동 대기"로 표시됩니다.

[봇 Render 환경변수]
PUBLIC_FEED_ENABLED=1
PUBLIC_BASE_URL=https://본인의-Render-서비스주소.onrender.com
PUBLIC_FEED_ALLOWED_ORIGIN=https://본인의-GitHub-Pages-주소

[확인 주소]
https://본인의-Render-서비스주소.onrender.com/health
https://본인의-Render-서비스주소.onrender.com/api/status
https://본인의-Render-서비스주소.onrender.com/api/events?limit=8

[브라우저 알림]
홈페이지의 "브라우저 알림 켜기" 버튼을 누르면 페이지가 열려 있는 동안 새 공개 이벤트를 알립니다.
브라우저가 완전히 종료된 상태에서의 푸시 알림은 별도 Web Push 서버가 필요해 이번 버전에는 포함하지 않았습니다.

[디자인]
- 전체 페이지를 검은 성당·핏빛 봉인·금빛 룬 중심의 고딕 테마로 전면 개편했습니다.
- 외부 이미지 파일 없이 CSS 배경과 도형으로 구성해 파일 누락 위험을 줄였습니다.
- 모바일 레이아웃과 명령어 검색 기능을 유지합니다.
