ABADDON v12.2.0 — 혼돈의 축제 완전판
배포일: 2026-08-05

v12.0.0부터 v12.2.0까지 계획한 대규모 재미 기능을 하나의 통합 패치로 추가했습니다.

[돌발 이벤트]
- 황금 고블린, 수상한 보물상자, 운석 낙하, 유령 출몰, 은행 강도, 아바돈 폭주, 행운의 시간, 저주의 시간
- 서버별 자동 출현은 기본 꺼짐
- 서버 관리자가 채널·역할 멘션·출현 간격을 설정
- 이벤트 ID별 중복 보상 차단과 서버별 진행 상태 저장

[파티게임]
- 폭탄 돌리기, 마피아, 라이어 게임, 그림자 추리, 생존 룰렛, 배신 심리전
- 참가 → 시작 → 선택/투표 → 결과 흐름
- 마피아 역할, 라이어 단어, 비밀친구 대상은 개인 메시지로 전달
- 오래 방치된 방은 자동 종료하고 진행 데이터는 서버별로 격리

[NPC·동료]
- NPC 6명 대화·선물·친밀도·관계도
- 동료 8종 획득·먹이·탐험·진화·도감·펫 레이스
- 동료 효과는 승패 조작이 아닌 수집·진행 중심

[탐험·던전]
- 폐허, 심해, 저주받은 카지노, 유령 열차, 달 기지, 악마 시장, 화투 신전, 시간의 미궁
- 개인·파티 탐험과 선택형 진행
- 탐험 ID, 단계, 체력, 보물과 선택 이력을 저장해 재시작 후 계속 진행
- 운석·아바돈 폭주는 서버 공동 보스형 이벤트로 작동

[사업 경영]
- 카페, 카지노, 경마장, 탐정사무소, 방송국, 장난감 가게, 용병 길드, 화투 공방
- 개설·상품·직원·방문·평점·정기 수익·서버 상권 순위
- 날짜와 사업 상태를 기반으로 정산하여 같은 기간 중복 수익을 차단

[예능·친목]
- 오늘의 명장면, 주간 예능, 월간 시상식, 불운왕, 역전왕, 블러프 분석
- 운세, 궁합, 밸런스, 월드컵, 랜덤 벌칙, 칭찬 릴레이, 비밀친구, 서버 빙고, 출석, 생일 카드
- 익명 응원은 URL 차단, 대량 멘션 무력화, 관리자 감사 로그와 신고 기능 포함

[꾸미기·비밀 콘텐츠]
- 칭호, 배경, 카드 뒷면, 테이블 스킨, 개인·서버 트로피룸
- 자정 상인, 숨겨진 임무, 비밀 결승 조건, 서버에 하나뿐인 전설 유물
- 재미 점수와 실제 활동 조건으로 해금하며 같은 보상은 한 번만 지급

[운영·안전]
- !혼돈설정, !이벤트설정, !친목설정
- !혼돈백업, !혼돈복구
- !1220통합검수 상세, !테스트 상세, !패치노트 최신화
- 한국어와 English 명령·화면 분리
- 기존 v11.9.0 일정·중계·업적, 카드게임, 화투, 포커 기능 유지
