ABADDON v7.5.0 Render 배포·실서버 테스트 가이드

1. 배포 전 백업
- Render Persistent Disk의 /var/data/survival_data.json을 별도 보관
- 봇에서 !백업생성 후 !백업검증 실행
- 현재 환경변수, 시작 명령, Persistent Disk 마운트 경로 확인
- 이번 패치는 삭제 0건이지만 데이터 이관 전 원본 백업은 필수

2. 봇 배포
- ABADDON_BOT_v7.5.0_GUILD_RAID_INTEGRATION_PATCH.zip의 내용을 프로젝트 루트에 배포
- requirements.txt와 apocalypse_bot 폴더가 루트에 있어야 함
- 기존 Render 시작 명령은 변경하지 않음

3. Render 로그 확인
- SyntaxError, ImportError, CommandRegistrationError가 없어야 함
- v7.5.0 길드 통합 등록 완료 로그 확인
- 패치 자동 공지가 지정 채널에 같은 버전으로 한 번만 게시되는지 확인

- 마지막 길드원이 나간 테스트 길드가 삭제되지 않고 휴면 상태가 되는지 확인

- !길드거래내역에 입금·출금 기록이 남는지 확인

- 토벌 후 보상을 동시에 두 번 요청해도 한 번만 지급되는지 확인

10. 스토리 회귀 검사
- 일반 미완료 계정에서 !시즌2 시작이 잠기는지 확인
- 시즌 1 완료 후 시즌 2가 해금되는지 확인
- 관리자 계정에서 시즌 2·3·4가 모두 즉시 실행되는지 확인
- 기존 시즌 2~4 진행자가 잠기지 않는지 확인

11. 홈페이지 배포
- ABADDON_OFFICIAL_SITE_v7.5.0_UPLOAD.zip 내용물을 홈페이지 루트에 업로드
- v7.5.0 표시, 길드·기지·금고·레이드 소개, 명령 검색 확인
- 브라우저 강력 새로고침 후 v750 캐시가 적용되는지 확인

12. 문제 발생 시
- 새 데이터 파일을 덮어쓰지 말고 Render 로그와 백업을 보존
- !길드검수와 !750안정화검수 결과를 캡처
- 원본 survival_data.json과 문제 발생 직후 파일을 각각 보관
- 폐기·수동 데이터 삭제는 관리자 승인 전 실행하지 않음

검증 한계
- 정적 컴파일, 모의 명령 등록, 데이터 이관, 동시성·정산 테스트는 통과함
- 실제 Discord Gateway 로그인과 Render 실부팅은 제작 환경에서 수행하지 못했으므로 위 연기 검사가 최종 확인 단계임
