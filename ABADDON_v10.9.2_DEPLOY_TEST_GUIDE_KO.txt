ABADDON v10.9.2 배포 및 실제 적용 확인 가이드

1. 봇 배포
- 기존 Render 서비스의 저장 데이터와 환경변수를 백업합니다.
- ABADDON_BOT_v10.9.2_VISUAL_DASHBOARD_LIVE_RACING_ONLINE_AUDITED_PATCH.zip을 새 소스로 배포합니다.
- 이전 빌드 캐시가 남아 있으면 Clear build cache & deploy를 사용합니다.
- 시작 로그에서 다음 문장을 찾습니다.
  [ABADDON v10.9.2] visual_dashboards=5 horse_racing=live online_feed=fallback+api recovered_races=...
- 이 로그가 없으면 이전 코드가 실행 중입니다.

2. 필수 Discord 확인 순서
- !테스트 상세
- !패치노트
- !정보
- !생존대시보드
- !세계지도
- !지도대시보드
- !카드대시보드

판별 기준:
- !정보와 !생존대시보드에 abaddon_survivor_dashboard.png가 표시되어야 합니다.
- !세계지도와 !지도대시보드에 abaddon_world_map.png가 표시되어야 합니다.
- !카드대시보드에 abaddon_card_catalog.png와 종목 선택 메뉴가 함께 표시되어야 합니다.
- 이전 텍스트 정보만 나오면 v10.9.2가 실제 배포되지 않은 것입니다.

3. 실시간 경마 확인
- !경마장
- !경마 10000
- 한 말을 선택합니다.
- 약 1.4초마다 동일 메시지의 말 위치가 이동하는지 확인합니다.
- 마지막 결과에서 우승마, 내 선택, 총 지급, 이번 게임 +/-칩, 잔액 전→후가 나오는지 확인합니다.
- !경마전적에서 플레이 수와 누적 손익이 저장되는지 확인합니다.
- !아바돈초대 경마 10000으로도 같은 경주가 시작되는지 확인합니다.

4. 음수와 중단 복구 확인
- 테스트 계정의 칩보다 큰 판돈으로 경마를 시작해 음수 잔액이 저장되는지 확인합니다.
- 최대 판돈 차단 문구가 없어야 합니다.
- 테스트 중 프로세스를 강제 재시작한 경우, 다음 부팅에서 recovered_races가 1 이상이고 미정산 판돈이 환불되는지 확인합니다.
- 정상 종료된 경주는 중복 환불되지 않아야 합니다.

5. 홈페이지 배포
- ABADDON_OFFICIAL_SITE_v10.9.2_UPLOAD.zip의 내용을 정적 사이트 루트에 덮어씁니다.
- 브라우저 캐시 또는 CDN 캐시를 비우고 ?v=1092 파일이 로드되는지 확인합니다.
- 메인 화면 ONLINE 글자와 초록 상태등을 확인합니다.
- 실시간 종말 기록 영역이 보이는지 확인합니다.
- PNG 정보·지도·카드 도감 미리보기 3장이 보이는지 확인합니다.
- 경마 미리보기의 말이 좌우로 움직이는지 확인합니다.
- 봇 초대와 공식 Discord 버튼을 확인합니다.

6. 실제 온라인 수치 연결(선택이지만 권장)
A. 홈페이지 ZIP의 live-service 폴더를 별도 Render Web Service로 배포합니다.
B. Web Service의 PUBLIC_FEED_RELAY_KEY를 확인합니다.
C. 봇 Background Worker 환경변수:
   PUBLIC_FEED_RELAY_URL=https://해당-서비스.onrender.com
   PUBLIC_FEED_RELAY_KEY=동일한-비밀키
   PUBLIC_FEED_HEARTBEAT_SECONDS=45
D. 홈페이지 config.js:
   eventFeedUrl: "https://해당-서비스.onrender.com"
E. Discord 확인:
   !실시간피드 켜기
   !실시간피드테스트
   !실시간피드상태
F. 홈페이지에서 연결 서버, 생존자, 지연시간, 마지막 신호가 실제 값으로 바뀌는지 확인합니다.

7. Render 경고 회귀 확인
- v1000_global_survivor.py에서 TextInput.label is deprecated 경고가 다시 반복되지 않는지 확인합니다.
- 경고가 나오면 서버가 v10.9.1 이전 파일을 섞어 실행 중일 가능성이 큽니다.

8. 알려진 검수 한계
제작 환경에는 discord.py와 실제 Discord 토큰이 없어 Gateway 로그인, 실제 권한, 여러 사용자의 동시 버튼 클릭은 자동 실행하지 못했습니다. Python 전체 컴파일, 순수 경마 규칙 1,000회 시뮬레이션, PNG 생성, 홈페이지 JS/HTML/링크, 공개 피드 HTTP 송수신은 오프라인에서 검증했습니다.
