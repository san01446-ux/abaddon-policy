ABADDON v11.6.0 배포·실제 테스트 가이드

1. 백업
- 현재 운영 ZIP, 데이터 파일, 환경변수를 별도 보관합니다.
- Render 사용 시 배포 전 Persistent Disk와 데이터 경로를 확인합니다.

2. 배포
- 새 BOT ZIP을 저장소 루트 기준으로 덮어씁니다.
- Clear build cache & deploy를 권장합니다.
- 정상 부팅 로그:
  [ABADDON v11.6.0] checkpoints=15s recoverable_games=25 exact_refund=enabled result_once=enabled afk_policies=5 hwatu_audit=48 ruling_log=public_only

4. 복구 테스트 서버 점검
A. 텍사스 홀덤 또는 고스톱을 아바돈과 시작합니다.
B. 한두 번 행동/레이즈 후 Render를 재시작합니다.
C. !게임복구목록으로 체크포인트를 확인합니다.
D. !게임복구 [ID] 또는 !게임재개 [ID]를 실행합니다.
E. 복구가 불가능한 테스트 판은 !게임강제환불 [ID]로 실제 납부액이 한 번만 돌아오는지 확인합니다.
F. 같은 환불 명령을 다시 실행해 중복 환불이 차단되는지 확인합니다.

5. 잠수 규칙 테스트
!턴시간설정 20
!잠수규칙설정 아바돈대행
- 사람 차례에서 20초가 지난 뒤 정책대로 처리되는지 확인합니다.
- 체크/폴드/일시정지/환불도 테스트 서버에서 각각 확인합니다.

6. 결과 보장 테스트
- 게임 종료 후 승자·패자·족보/이유·팟·이번 손익·이전→현재 잔액·정산 ID가 한 번만 표시되는지 확인합니다.
- 결과 메시지를 테스트 중 삭제해 새 결과 메시지 복구 경로를 확인합니다.

7. 판정 요청
