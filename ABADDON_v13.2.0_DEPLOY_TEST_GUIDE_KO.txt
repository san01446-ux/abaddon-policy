ABADDON v13.2.0 배포·실제 서버 테스트 가이드

1. 기존 v12.2.0 데이터 폴더와 환경 변수를 백업합니다.
2. 새 BOT ZIP을 별도 폴더에 풀고 기존 데이터 파일을 유지한 채 배포합니다.
3. 시작 로그에서 runtime_hotfix=enabled와 black_city=enabled를 확인합니다.
4. 먼저 !오류검수, !1320통합검수 상세, !테스트 상세를 실행합니다.
5. 오류 재현 확인: !혼돈축제 → 돌발 이벤트 → 선택 버튼을 눌러 50035/10062가 다시 발생하지 않는지 확인합니다.
6. 도시 흐름: !도시개설 테스트도시 → !도시 → !도시지도 → !도시직업선택 대장장이 → !도시채집 → !도시제작법을 확인합니다.
7. 거래 흐름은 테스트 계정 두 개로 판매등록 → 구매 → 같은 판매 ID 재구매 차단 → 취소 환불을 확인합니다.
8. !도시알림채널 #채널 후 !도시설정 뉴스 켜기처럼 명시적으로 설정한 경우만 자동 게시되는지 확인합니다.
9. !도시백업으로 백업 ID를 만들고 작은 설정 변경 뒤 !도시복구 ID로 되돌립니다.
10. 홈페이지 black_city_public.json은 기본 연동 대기입니다. 공개가 필요한 배포에서만 ABADDON_PUBLIC_EXPORT를 웹 루트 파일 경로로 지정하고 !도시설정 공개 켜기를 사용합니다.

제작 환경에서는 Discord Gateway 접속과 실제 HTTP 50035 재현, 다중 사용자 동시 상호작용, 장시간 시즌 스케줄을 실행하지 못했습니다. 테스트 서버에서 위 흐름을 완료한 뒤 운영 서버에 적용하세요.
