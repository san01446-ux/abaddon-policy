ABADDON v17.0.0 배포·테스트 가이드

배포 전
1. 기존 데이터 파일, .env, 봇 토큰과 서버 설정을 백업합니다.
2. 실행 중인 봇 프로세스를 완전히 종료합니다.
3. 새 ZIP을 별도 폴더에 풀고 기존 데이터만 복사합니다.
4. Python 의존성을 기존과 동일하게 유지합니다.
5. 봇을 완전히 재시작합니다. 모듈 리로드만으로는 이전 콜백이 남을 수 있습니다.

핵심 런타임 확인
- !정보 화면 버튼을 연속으로 눌러 _MissingSentinel.author가 재발하지 않는지 확인
- !명령어 드롭다운과 실행 버튼 확인
- 결과·추천 버튼이 delete_after Webhook 오류 없이 전송되는지 확인
- !오늘할일, !장비를 미가입 사용자와 가입 사용자 각각 확인
- 같은 버튼 오류 안내가 중복으로 2회 뜨지 않는지 확인

콘텐츠 공방 확인
- !콘텐츠공방 → 새 사건
- 선택지 2~5줄 저장
- 미리보기 테스트에서 재화가 변하지 않는지 확인
- 공개 후 !콘텐츠목록과 !사용자사건에서 실행
- 같은 사건을 두 번 완료할 때 보상이 중복되지 않는지 확인
- 한국어 사용자와 English 사용자의 화면이 섞이지 않는지 확인

시즌 6 확인
- !시즌6시작
- 두 계정 이상으로 선택지 투표
- 투표 변경 후 집계 확인
- !시즌6결정으로 1개 장 확정
- 봇 재시작 후 장·투표·지표·연대기 복구 확인
- 최종 장 완료 후 !시즌6보상 중복 수령 차단 확인
