1. 저장하는 정보

  • Discord 사용자 ID와 서버(guild) ID
  • 게임 진행, 재화, 장비, 퀘스트, PvP·길드 활동 및 서버별 설정값
  • 명령어 사용·오류·복구 등 서비스 운영에 필요한 기록

2. Discord 로그인과 OAuth

웹 마이페이지와 서버 대시보드는 Discord OAuth의 identify 및 guilds 범위를 사용합니다. 사용자 ID·표시 이름·아바타를 확인하고, guilds 정보는 사용자가 관리할 수 있는 ABADDON 서버를 판별하는 데 사용합니다. Discord 비밀번호를 수집하지 않으며 OAuth access token은 게임 저장 데이터에 기록하지 않습니다.

3. 이용 목적

게임 진행 저장, 랭킹·마이페이지 표시, 서버 설정 관리, 오류 분석, 서비스 운영 및 데이터 복구를 위해 사용합니다.

4. 보관과 삭제

서비스 운영 중 필요한 데이터를 보관합니다. 삭제 요청은 공식 Discord 지원 채널을 통해 접수할 수 있으며, 운영·복구용 백업에는 제한된 기간 동안 이전 기록이 남을 수 있습니다.

5. 제3자 서비스

Discord OAuth, 선택형 AI 제공자, 한국 디스코드 리스트 투표 확인 기능 등을 사용할 수 있습니다. 외부 AI 기능이 활성화된 경우 사용자가 AI 기능에 직접 입력한 메시지와 기능 수행에 필요한 제한된 최근 대화가 설정된 AI 제공자에게 전송될 수 있습니다. 투표 보상 확인 시 Discord 사용자 ID가 투표 확인 API 요청에 사용될 수 있습니다. 해당 기능이 비활성화되어 있으면 관련 외부 전송은 발생하지 않습니다.

6. 웹 세션과 대시보드 중계

ABADDON 웹 세션 토큰은 브라우저에 임시 저장되며 기본적으로 약 12시간 후 만료됩니다. 인증된 대시보드 변경 요청은 Live Feed Web Service를 통해 Bot Worker로 중계됩니다. Discord Bot Token은 브라우저나 공개 홈페이지에 전달되지 않습니다.

7. 외부 콘텐츠 알림

서버 관리자가 YouTube·Twitch·치지직(CHZZK)·SOOP 알림을 활성화하면 새 영상 또는 방송 시작 여부를 확인하기 위해 공개 채널 ID·핸들·로그인명·스트리머 ID가 해당 플랫폼의 공개 페이지 또는 API 요청에 사용될 수 있습니다. API Key·Client ID·Client Secret 등 인증 정보는 서버 환경변수에 저장하며 공개 홈페이지에 노출하지 않습니다.

멤버가 알림 등록을 요청하는 기능을 사용할 경우 요청자 Discord ID, 플랫폼, 제출한 공개 채널 식별자, 검토 상태 및 검토자 ID가 서버 설정 데이터에 저장될 수 있습니다.
