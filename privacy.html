개인정보처리방침

시행일 2026년 7월 30일

본 방침은 Discord 봇 ‘아바돈(ABADDON)’의 데이터 처리 방식을 설명합니다.

1. 처리하는 정보

아바돈은 서비스 제공에 필요한 범위에서 다음 정보를 처리할 수 있습니다.

  • Discord 식별정보: 사용자 ID, 서버 ID, 채널 ID, 역할 ID, 스레드 ID 및 메시지 ID
  • 게임 데이터: 가입 여부, 레벨·경험치·재화, 인벤토리, 장비, 직업, 전투·탐험·퀴즈·출석·미션·도감·길드·거래·침공·스토리 진행 기록
  • 서버 설정: 알림 채널, 알림 역할, 기능 활성화 상태 등 서버 관리자가 지정한 설정
  • 명령 처리 정보: 사용자가 봇 명령어로 입력한 내용. 명령 실행을 위해 일시적으로 처리되며, 별도로 저장되는 항목은 게임 진행 및 설정 데이터에 한정됩니다.

아바돈은 운영 코드 기준으로 이메일 주소, 전화번호, 실명, 결제정보, 정확한 위치정보 또는 사용자의 Discord 비밀번호를 직접 수집하지 않습니다.

2. 이용 목적

  • RPG 계정 생성과 게임 진행 저장
  • 전투, 탐험, 제작, 거래, 랭킹, 퀴즈, 도감, 튜토리얼, 스토리 등 기능 제공
  • 서버별 알림 채널과 기능 설정 유지
  • 부정 이용 방지, 오류 조사, 서비스 안정성 유지

3. 공개될 수 있는 정보

랭킹, 길드, 거래, 파티, PvP, 침공 및 기타 게임 기능을 이용할 때 Discord 표시 이름, 멘션, 게임 기록의 일부가 해당 Discord 서버의 다른 이용자에게 표시될 수 있습니다. 표시 이름은 응답 생성 시 Discord에서 제공받아 표시하며, 게임 저장 파일에는 주로 Discord 사용자 ID와 게임 데이터가 저장됩니다.

4. 보관 장소와 기간

데이터는 아바돈 운영 서버의 저장 파일 또는 운영에 필요한 호스팅 환경에 보관될 수 있습니다. 사용자 게임 프로필은 Discord 사용자 ID를 기준으로 관리되므로 여러 서버에서 동일한 진행 데이터가 사용될 수 있습니다.

데이터는 서비스 제공에 필요한 동안 보관하며, 이용자의 삭제 요청, 서비스 종료 또는 더 이상 보관할 필요가 없는 경우 합리적인 기간 내 삭제합니다. 법령상 보관 의무가 있는 경우에는 해당 기간 동안 보관할 수 있습니다.

5. 제3자 제공 및 처리 위탁

아바돈은 이용자 데이터를 판매하지 않습니다. 서비스 제공 과정에서 Discord 및 호스팅·인프라 제공업체가 기술적으로 데이터를 처리할 수 있습니다. 법적 의무 이행, 이용자의 명시적 요청 또는 서비스 운영에 필수적인 경우를 제외하고 임의로 제3자에게 제공하지 않습니다.

6. 데이터 삭제·열람·정정 요청

이용자는 자신의 게임 데이터에 대한 열람, 정정 또는 삭제를 요청할 수 있습니다. 요청 시 본인 확인을 위해 Discord 사용자 ID를 확인할 수 있으며, 데이터 삭제는 복구할 수 없고 모든 서버에서 공유되는 아바돈 게임 진행이 함께 삭제될 수 있습니다.

문의 방법: Discord의 아바돈 앱 프로필에 등록된 지원 서버 또는 봇 운영자를 통해 요청해 주세요.

7. 보안

운영자는 접근 제한, 토큰 비공개 관리 등 합리적인 보호조치를 적용합니다. 다만 인터넷을 통한 전송과 전자적 저장에 절대적인 보안을 보장할 수는 없습니다.

8. Discord 및 이용 자격

아바돈 이용자는 Discord의 이용약관과 커뮤니티 가이드라인을 준수해야 하며, Discord 서비스를 이용할 수 있는 연령 및 자격 요건을 충족해야 합니다.

9. 방침 변경

기능 또는 법적 요구사항이 변경되면 본 방침을 수정할 수 있습니다. 중요한 변경은 본 페이지, 봇 공지 또는 지원 서버를 통해 알릴 수 있으며, 상단 시행일을 갱신합니다.
