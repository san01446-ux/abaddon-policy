개인정보처리방침

최종 수정: 2026-08-13

1. 저장하는 정보

  • Discord 사용자 ID와 서버 ID
  • 게임 진행, 재화, 장비, 퀘스트, PvP·길드 활동, 설정값
  • 운영 안정화를 위한 오류·복구 기록

2. Discord 로그인

웹 마이페이지는 Discord OAuth의 identify 범위로 사용자 ID·표시 이름·아바타를 확인합니다. Discord 비밀번호를 수집하지 않습니다. OAuth access token은 게임 저장 파일에 보관하지 않으며, 웹 세션은 제한된 시간 동안만 유지합니다.

3. 이용 목적

게임 진행 저장, 랭킹·마이페이지 표시, 서버 운영 및 데이터 복구를 위해 사용합니다.

4. 보관과 삭제

서비스 운영 중 게임 진행을 보관하며, 삭제 요청은 공식 Discord 문의 채널을 통해 접수할 수 있습니다. 백업에는 일정 기간 이전 기록이 남을 수 있습니다.

5. 제3자 서비스

Discord OAuth, 선택형 AI API, 한국 디스코드 리스트 투표 확인 기능을 사용할 수 있습니다. 외부 AI가 활성화된 경우 !AI동료에 입력한 메시지와 제한된 최근 대화가 설정된 AI 제공자에게 전송될 수 있습니다. 투표 보상 확인 시 Discord 사용자 ID가 한국 디스코드 리스트의 투표 확인 API 요청에 사용됩니다. 각 기능이 비활성화된 경우 해당 외부 전송은 발생하지 않습니다.

6. 웹 세션

마이페이지 로그인용 ABADDON 세션 토큰은 브라우저에 임시 저장되며 기본 12시간 후 만료됩니다. Discord OAuth access token은 게임 저장 데이터에 기록하지 않습니다.

7. 외부 콘텐츠 알림

서버 관리자가 YouTube 또는 Twitch 알림을 활성화하면, 새 영상·방송 시작 여부를 확인하기 위해 공개 채널 ID 또는 로그인명이 해당 플랫폼 API에 전송됩니다. API Key와 Client Secret은 서버 환경변수에만 저장하며 공개 홈페이지에 노출하지 않습니다.
