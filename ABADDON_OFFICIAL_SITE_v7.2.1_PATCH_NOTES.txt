ABADDON v7.2.1 — 서버 채널 가이드 패치

패치 날짜: 2026-08-03

[핵심 변경]
- 공식 서버 메뉴 이름에 맞춘 채널 전용 고정 안내 37종
- 비상 방송, 생존 수칙, 가입, 작전, RPG, 정보실, 도박, 무전, 관리 채널별 문구 분리
- !채널가이드 전체설치 한 번으로 이름이 맞는 채널 자동 탐색
- 기존 아바돈 관리 메시지는 새로 쌓지 않고 편집·갱신
- 채널 보기, 메시지 보내기, 링크 임베드, 기록 보기, 메시지 관리 권한 사전 검사
- 음성 채널 채팅이 메시지 API를 지원하는 환경에서는 무전/음성 안내도 고정
- 범용 규칙 드롭다운은 25종을 유지해 Discord 선택 메뉴 제한 준수
- v7.2.0 통합 환영, 역할, 패치 자동 공지, 아바돈 AI 미니게임 유지
- v7.0.2 데이터 보호 및 백업 별칭 핫픽스 유지
- 신규 이미지 0장

[관리 명령]
!채널가이드 전체설치
!채널규칙 자동
!채널규칙 상태
!채널규칙 갱신
!채널규칙 일괄상태
!채널규칙 일괄중지
!채널규칙 일괄시작

[적용 방식]
- 첫 실행은 메뉴 이름과 정확히 일치하는 채널을 찾아 작업 계획을 생성합니다.
- 채널마다 20초 간격으로 작성·고정해 Discord API 과부하를 방지합니다.
- 같은 명령을 다시 실행하면 기존 관리 메시지를 찾아 최신 문구로 수정합니다.
